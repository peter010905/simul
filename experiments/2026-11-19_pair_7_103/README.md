# Gazebo 실험 · 10cm 간격의 Original ArUco 7과 103

두 ID를 각각 등록하고 각각 1.5m 이내에 실제로 접근한 시행은 기존 Flow v3 3/3, Mixed 3/3, 원본 R32 0/3이었다. 범퍼 접촉은 아홉 번 모두 0회였다.

## 실험 조건

- 한 변이 8cm인 검은 마커 두 개를 같은 벽에 나란히 부착했다. 중심 간격은 10cm, 검은 테두리 사이 간격은 2cm, 높이는 45cm다. 두 장의 흰 바탕은 서로 겹치지 않는다.
- 5.6m × 4.8m 직사각형 방, 동일한 Gazebo SDF와 TurtleBot4, 640 × 480 RGB 카메라를 사용했다. 로봇은 두 마커 정면 약 2.21m에서 출발했다. 다른 마커나 이동 장애물은 없었다. 관측자는 실제 시뮬레이터 월드의 로봇 중심과 각 마커 중심 사이의 수평거리를 기록했다.
- 실물 보드의 세 작업공간을 사용했다. Flow 두 종은 face_intent_v2, MPPI, RGB·LiDAR 설정을 사용했다. 원본 R32는 b1ed300의 실물 프리셋에 모의 시계와 120초 예산을 적용했다. 다른 주행·마커 임계값은 각 정책의 값을 사용했다. 월드 진실값은 외부 평가기에만 입력했다.
- 공통 성공 조건은 두 ID가 동시에 등록 목록에 있고, 각 ID가 등록된 상태에서 실제 1.5m 이내 위치가 적어도 한 번씩 관측된 것이다. 이 조건 달성, 정책 자체 종료 또는 120초 한도 중 먼저 온 시점에 측정을 끝냈다. Flow와 Mixed는 실제 저장한 markers.csv도 확인했다. 원본은 latest.json이 가리키는 저장본을 확인했다. 이 기록은 두 마커 시험의 결과이며 세 마커 전체 미션의 완주 기록은 아니다.
- 시작 서비스 승인부터 측정했다. 아래 진입·종료 시간은 Gazebo 초, 실제 경과는 VM 벽시계 초다. 시작 준비 시간은 제외했다. 범퍼 채널에 접촉 신호가 새로 들어올 때 한 번으로 셌다. 최종 거리와 진입 시각은 진실 궤적 CSV로 독립 재계산했다.
- 세 정책을 동시에 실행하지 않고 1차 기존 → Mixed → 원본, 2차 Mixed → 원본 → 기존, 3차 원본 → 기존 → Mixed 순으로 실행했다.

## 해석

두 ID의 등록·접근 완료 중앙값은 기존 7.81초, Mixed 7.61초였다. 세 번씩의 정면 시험에서 차이가 0.20초였다. Mixed의 세 로그에서 첫 목표는 모두 focus, 다음은 approach였다. 복도 우회나 장애물 뒷면 탐색의 우위는 이번 배치로 평가할 수 없다.

원본 R32도 세 번 모두 같은 영상에서 두 ID를 판독했다. 두 ID의 방향이 함께 나온 프레임은 각각 69·111·56장, 두 위치까지 동시에 나온 프레임은 47·92·31장이었다. 당시 추정한 두 점 간 거리의 시행별 중앙값은 10.28·10.29·10.40cm였다. 원본은 서로 다른 ID의 지도 위치가 35cm 안이면 결과 목록에 한 ID만 남긴다. 세 번 모두 저장된 ID는 7이었다. 실제 궤적 기준으로는 처음 두 번에 103에도 1.5m 안으로 들어갔다.

원본 1·2회는 약 16초를 남겨둔 시점에 남은 관찰 후보 16개 모두 예상 시간이 부족해 자체 time_limit으로 끝났다. 3회는 73.40초에 recorder_missing_or_stale로 종료됐다. 이때 7번과 103번까지 최소 거리는 각각 1.602m, 1.596m였다. 해당 회차는 표에 포함했다. 로봇·센서 준비 전 네임스페이스 설정 오류로 시작하지 못한 초기 기동 점검은 시행 수에서 제외했다.

## 재현

VM의 세 설치 작업공간과 ROS 2 Jazzy가 필요하다. 이 디렉터리를 VM의 쓰기 가능한 경로로 복사해 아래 명령을 순서대로 실행한다. 출력 디렉터리는 새 경로여야 한다. 스크립트는 로컬 루프백 ROS 도메인 173에서 Gazebo를 띄운다. 반복 시 새 출력 디렉터리 이름을 지정한다.

```bash
bash run.sh flow "$PWD/flow"
bash run.sh mixed "$PWD/mixed"
bash run.sh r32 "$PWD/r32"
python3 summarize.py "$PWD"
```
