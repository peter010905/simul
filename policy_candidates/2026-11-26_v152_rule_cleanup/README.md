부모 `.48`의 빠른 벽 순회 → 내부 탐색 흐름을 보존하면서 목표 선택 충돌을 정리한 별도 사본이다.

기존 작업공간·실물 보드·기본 선택은 변경하지 않았으며 실물 구동 명령을 발행하지 않았다.

## 정리한 충돌

| 기존 문제 | 수정 |
|---|---|
| 벽 순회 뒤 조기 반환이 지역 복귀·탈출·통합 선택까지 차단 | `CenterWall.decide`의 최종 선택을 한 경로로 정리. 벽 순회 이후 지역 복귀/탈출 → 제한된 박스 서비스 → 복구 → 표면/Frontier 비교 |
| 3.5m 내 박스가 있으면 새 공간 점수 계산 전 즉시 반환 | 현재 박스의 55초 연속 서비스만 보호. 이후 박스도 Frontier와 점수 비교 |
| 55초가 끝나도 일반 박스 선택이 동일 박스를 다시 예약 | 모든 일반 박스 선택에 동일한 서비스 예산 적용. 90초 보류 후 미완료 면 재평가; 실제 마커 접근은 별도 우선권 유지 |
| 성공한 위치도 실패 위치와 같은 제외 목록에 추가 | `excluded` 추가 제거. 실패는 기존 NavigationFlow의 45cm/60초 제한, 성공은 기존 위치+방향 관찰 기억으로 처리 |
| 중간 후보를 고르기만 해도 마커 시도 횟수와 대기시간 소모 | 최종 선택한 작업을 전달할 때만 Focus/Approach 기록 갱신. 경로 우회 접근 중복 기록 제거 |
| 관찰하지 못했어도 dispatch 횟수로 면을 제외 | 실제 실패와 RGB 관찰 증거 분리. FaceWork는 Nav2 성공·회전 성공만으로 OBSERVED를 부여하지 않음 |
| 지도 개선 후에도 실패 면을 재검토하지 않음 | 면 주변 49개 샘플에서 점유/미지/연결성의 의미 있는 변화 시 지역 실패 예산 재평가. 동일 지도 2회, 전체 6회 실패 상한 유지 |
| 현재 위치 여유 32cm 미만이면 피팅된 모든 면을 제거 | 검증된 출발 연결이 있으면 후보 생성 유지. 목적지 32cm 및 전역/지역 Costmap 조건 유지 |
| 상위 그래프의 30cm 원판 예외와 하위 안전 경로의 불일치 | 레거시 인자는 호환하되 점유/미지 셀을 열지 않고 기존 Grid의 최소 23cm·단조 여유 출발 연결만 사용 |
| 박스 완료 판단에 등록 ID와 접근 완료가 혼용 | 안전하게 물체에 귀속된 등록 ID를 박스 서비스 종료에 공통 사용. 임무 완료는 기존 직접 거리 1.5m 증거를 계속 요구 |
| 마커 주변 비용을 실제 경로 길이에 더함 | 거리와 의미적 이득 분리. 경로 시간은 실제 안전 격자 거리, 마커 주변 억제는 이득 배율로 반영 |
| 벽 관찰 거리 계산의 크기 가정 혼용 | 일반 관찰 거리의 보수적 최소 크기 가정을 WorkRules와 공유 |

`work_rules.py`는 주요 서비스 예산·면 일치·실패 재평가 기준을 모은다. 모든 ROS/Nav2 파라미터를
새 설정으로 이동시킨 것은 아니다. 기존 검출기, 물리 안전 감시, SLAM 및 Nav2 제어기는 재사용한다.

## 최종 선택 순서

1. 센서·주행 준비·접촉 보호는 기존 Mission이 담당한다.
2. 판독 ID의 접근과 확정된 영상 단서가 일반 탐색보다 우선한다.
3. 초기 벽 순회 동안 일반 관찰 정지를 추가하지 않는다.
4. 이후 중단된 지역 목적지 복귀 및 정체 지역 탈출을 실제 선택에 연결한다.
5. 현재 박스의 안전한 남은 면은 기존 55초 예산 안에서 이어 본다.
6. 실패 위치를 바꾸는 복구와 관찰 가능한 표면/Frontier의 공동 평가를 실행한다.
7. 벽은 경로의 부수적인 시각 이득에 포함하되 순회 후 일반 벽 탐색을 자동 재개하지 않는다.
8. 불가능한 면을 실제 관찰 완료로 바꾸지 않는다. 실패 이유와 재평가 횟수를 기록한다.
