# 실물 SLAM LiDAR 5m 설정

실물 보드의 Mixed v1.5.2.40과 v1.5.2.44 선택지는 SLAM 최대 레이저 사용 거리 5m 사본을 사용한다. 기존 12m 사본은 이름 끝에 LiDAR 12m (이전)이 붙은 별도 선택지로 보존했다.

두 사본은 src/osp_mission/config/slam.yaml의 max_laser_range를 12.0에서 5.0으로 변경했다. 설치된 robot.launch.py의 설정 생성 함수를 실행해 SLAM에 전달하는 YAML 값이 5.0인지 각각 확인했다. .40과 .44의 회전 지도 갱신 설정 차이도 각각 유지했다.

이 변경은 SLAM 입력의 최대 사용 거리 설정이다. 장치가 발행하는 원본 /scan의 측정 범위나 기존 근거리 충돌 감시 파라미터를 변경하지 않는다. 새 실물 주행 결과는 아직 없다.
