# Mixed v1.3.1 · 0.30 m/s 부드러운 주행·회전

v1.3의 막힘·스톨 복구를 이어받은 별도 작업 공간 `flow_v3_r32_smooth030_ws`이다. 사용자 제시 상한인 0.30 m/s를 MPPI와 속도 평활기의 전진 상한에 적용한다. 실물 보드에서는 **Mixed · 부드러운 주행·복구 (v1.3.1 · 0.30 m/s)**로 선택한다. 이전 0.45 m/s 실험 버튼을 실물 화면에서 제거하고, 원본은 Git 태그에 보존한다.

| 설정 | 이전 실물 구성 | v1.3.1 |
| --- | ---: | ---: |
| MPPI 전진 상한 | 0.45 m/s 실험 | 0.30 m/s |
| MPPI 전진 가속·감속 | +3.0 / −3.0 m/s² | +0.35 / −0.60 m/s² |
| 명령 평활기 전진 가속·감속 | +0.8 / −2.5 m/s² | +0.35 / −0.60 m/s² |
| MPPI 회전 가속 | 3.5 rad/s² | 0.70 rad/s² |
| 명령 평활기 회전 가속·감속 | +1.0 / −3.2 rad/s² | +0.70 / −0.90 rad/s² |
| 제자리 관찰 회전 가속 | 1.0 rad/s² | 0.70 rad/s² |
| 제자리 회전 끝의 최소 속도 | 0.15 rad/s | 0.10 rad/s |

최대 회전 속도는 0.50 rad/s이다. 전진·회전의 샘플링 표준편차는 각각 0.20→0.12 m/s, 0.40→0.20 rad/s로 조정했다. MPPI 예측과 실제 명령 가속 범위를 맞춰 출발·방향 전환의 급격한 명령 변화를 줄이려는 설정이다. 0.30 m/s까지의 이상적인 가속 시간은 약 0.86초이며 일반 감속으로 정지하는 시간은 약 0.50초이다. 실제 탑재 하중과 바닥 조건에서의 반응은 추가 측정이 필요하다.

충돌 감시, 비용지도·로봇 크기, 기존 안전 정지와 v1.3 스톨 복구는 기존 값을 사용하는지 검사했다. 최종 ROS 런치를 전개한 뒤 이전 `forward_045` 인자 유무 모두에서 0.30 m/s 상한이 적용되는 것도 확인했다. 실행 시 최종 설정은 주행 결과의 `artifacts/nav2_smooth_030.yaml`에 저장된다.

동작 프로필, 후방 안전, 복구, 마커 재관찰을 포함한 격리 검사 21개가 통과했다. 이 버전의 실제 주행 부드러움·스톨 빈도·완주 시간은 아직 측정하지 않았다.

## 설치

Jazzy VM의 저장소 루트에서 준비된 v1.3 작업 공간을 입력으로 사용한다.

```sh
source /opt/ros/jazzy/setup.bash
candidate="$PWD/policy_candidates/2026-11-20_mixed_smooth_030"
python3 "$candidate/install.py" ~/flow_v3_r32_stall_recovery_ws ~/flow_v3_r32_smooth030_ws
cd ~/flow_v3_r32_smooth030_ws
colcon build --packages-select osp_mission
source install/setup.bash
```
