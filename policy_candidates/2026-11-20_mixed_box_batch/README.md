# Mixed 상자 면 묶음 관찰

상자 면 관찰 이력 공유 버전을 복사해 설치하는 시뮬레이션용 정책이다. 기준 작업공간은 `flow_v3_r32_shared_face_final_ws`, 후보 작업공간은 `flow_v3_r32_box_batch_ws`이다.

- 관찰할 면은 기존 Mixed의 카메라 관찰 기록, SLAM 연결성, 지도 여유, 가시선, Nav2 비용지도 검사를 통과해야 한다. 여러 시점에서 확인한 상자 중심과 관찰면을 오도메트리 좌표로 연결한다. 로봇이 직전에 선택한 상자의 2.3 m 안에 있고 미시도 면의 안전 경로가 3.5 m 이내면 그 면을 우선한다. 추정이 모호하면 상자 우선권을 주지 않는다.
- 센서 기반 근거리 접근 검증을 마친 마커의 위치가 상자와 연결되면 그 상자의 나머지 면은 보류한다. 다른 상자·탐색 경계·벽 목표를 선택할 수 없을 때 다시 후보로 사용한다. 마커 단서와 새 ID 접근은 계속 우선한다.
- 새 ID 등록은 미션의 다음 준비된 제어 주기에 재평가한다. 일반 이동이나 관찰 회전을 취소하고 새 계획을 세운다. 같은 등록 목록이 반복 수신돼도 같은 취소를 반복하지 않는다. 접촉 복구 중에는 등록 알림을 보관하고, 이미 유효한 확정 마커 접근을 수행 중이면 그 접근을 이어간다.
- 벽에서의 흑백 인쇄물 탐지 조건은 두 정책에서 같다. 지도 정답과 상자에 부착된 마커 ID는 정책이 읽지 않는다.

## 재현

Jazzy VM의 기존 작업공간을 입력으로 별도 작업공간을 만든다.

```sh
python3 install.py ~/flow_v3_r32_shared_face_final_ws ~/flow_v3_r32_box_batch_ws
(cd ~/flow_v3_r32_box_batch_ws && source /opt/ros/jazzy/setup.bash && colcon build --packages-select osp_mission)
bash run_one.sh shared-track-7MgfZqWs
```

`run_one.sh`는 원본 회차의 월드와 설정을 연결하고 VM 내부 통신으로 실제 Gazebo 주행을 실행한다. 회차 이름이 이미 존재하면 중단한다. `compare.py 기준폴더 수정판폴더`는 두 로그의 월드 해시, 배치, 첫 로봇 위치·방향을 대조한다.

## 지표

- 마커 접근 성공은 해당 ID 등록 후, Gazebo 실제 로봇 중심과 마커 사이 거리가 1.5 m 이내가 된 경우다. 서로 다른 ID 세 개가 모두 조건을 만족하면 그 지도를 완주한 것으로 센다.
- 상자 방문은 로봇 중심이 상자 중심의 1.75 m 이내에 들어올 때 시작하고 2.0 m 밖으로 나갈 때 끝난다. **상자 간 왕복 거리**는 다른 상자를 방문한 뒤 이전에 방문했던 상자로 되돌아올 때, 직전 상자에서 나간 지점부터 재진입까지 기록된 이동 거리다. 처음 찾아간 상자, 같은 상자 주변에서 연이어 면을 바꾼 이동, 중간에 다른 상자를 거치지 않은 단독 재접근은 합산하지 않는다. 이 지표에는 필요한 재관찰과 우연히 상자 곁을 통과한 거리도 포함될 수 있다.
