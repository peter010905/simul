# Mixed v1.5.2 Visual Survey

이 후보는 Mixed v1.5.1-balanced의 주행과 Balanced Print의 ArUco 판독을 계승한다. 8780 시험장의 벽과 서로 가리는 장애물에서, 다음 목표를 고르는 방식을 바꿨다.

| 상황 | 다음 관찰 위치를 고르는 방식 |
|---|---|
| 상자 주위에서 안 본 면이 남음 | 카메라로 관찰하지 못한 면을 독립적으로 평가한다. 한 면의 마커에 접근을 마쳐도 다른 면은 남는다. |
| 다른 각도에서 같은 길에 재진입 | 실제 주행거리 3m 이상, 1.05m 이상 이탈, 14초 이상 차이, 최근 네 위치 중 세 곳 이상이 이전 경로의 48cm 안에 있는지 검사한다. 최근 20초에 새 표면 증거가 있으면 계속 관찰한다. |
| 새로 보이는 면 없이 겹친 장애물 주위를 반복 | 처음 보는 인접 면에 한 번 기회를 주고, 이후 다른 벽·장애물 또는 미방문 지점으로 목표를 옮긴다. 기존 통로를 통과해야 하는 먼 목표도 선택할 수 있다. 군집 회피는 45초 후 풀린다. |
| 상자를 보는 동안 벽이 밀림 | 10분 시험에서는 대략 60초마다 미관찰 벽 구간에 기회를 준다. 카메라 방향·거리·표면 법선·가림·주행비용을 고려해 한 자세에서 여러 구간을 볼 수 있는 지점을 고른다. 중간에 도달한 마커를 확인하는 절차가 우선한다. |
| 좁은 관찰 위치 | 연결된 여유 격자, 원래 비용지도, 시선 차단 검사와 기존 목표 거부 조건을 모두 통과해야 한다. 실제 Nav2 결과와 카메라 증거는 따로 저장한다. |

벽의 적정 거리는 실제 CameraInfo 초점거리, `survey_reference_marker_m`, `survey_readable_pixels`에서 계산한다. 기본 참고값 0.14m와 18px는 벽 쪽으로 향할 목표를 고르는 데 쓰인다. 실제 ID 등록과 1.5m 접근은 기존 검출기와 독립 평가기가 결정한다.

팀용 Jazzy 환경에서 별도 작업 공간에 설치할 수 있다.

```bash
./team-sim.sh setup ~/mixed_visual_survey_ws --policy visual-survey
OSP_SURVEY_DISTANT_HINTS=false ./team-sim.sh run ~/mixed_visual_survey_ws --random-layout --tables fixed --markers three
```

멀리서 번호가 일치한 단서를 이용해 이동하는 기능은 별도 실험이다. 서로 다른 두 카메라 위치에서 같은 Original 무늬가 반복 판독되고, 각도와 투영 오차 및 세 번의 위치 일치 검사를 통과해야 한다. 단서만으로 마커 등록이나 접근 점수를 주지 않는다. 사각 상자 다섯 개를 둔 정식 비교와 8780 보드에서는 이 기능을 끈다. 별도 재생 실험에만 적용할 수 있다.
