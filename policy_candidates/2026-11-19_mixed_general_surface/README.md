# Mixed · 일반 장애물 집중 탐색

`flow_v3_r32_side_ws`를 보존하고 별도 `flow_v3_r32_general_ws`에 설치한 후보이다. 상자 네 면이나 직각 코너로 분류되지 않은 큰 불규칙 사물도 지도에 실제로 관측된 점유/자유 공간 경계로 다룬다. 물체 종류는 판정하지 않는다.

1. 일반 탐색 목표로 주행 중인 로봇이 미관찰 표면 약 40cm 이상을 1.4m 안에서 보면 Nav2 목표를 취소하고 짧게 회전하거나, 이미 정면에 있으면 잠깐 멈춰 카메라 프레임을 더 받는다. 단일 시점만으로도 이 짧은 확인을 허용한다. 확정 마커 접근·마커 집중 관찰·인쇄 후보 재방문은 중간 관찰에서 제외한다. 기존 관찰기의 최대 8회·총 35초·15초 간격과 ROS/Nav2 충돌 검사를 유지한다.
2. 짧은 관찰이 정상 완료됐고 45초 안에 같은 근처의 미관찰 표면이 남아 있으면, 기존 지도와 최신 비용지도에서 연결된 자유 셀·가시선·후보 목표 차단을 확인한 뒤 별도 관찰 위치를 고른다. 이 추가 이동은 최대 3회, 합계 최대 5m, 한 번에 최대 2.5m이며 남은 미션 시간이 60초 미만이면 시작하지 않는다. 목표 실행 중에도 Nav2 충돌 검사가 유지된다.
3. 추가 관찰 가치가 없거나 접근 가능한 지점이 없으면 원래 Flow/R32 탐색을 계속한다. 상자로 확인된 경우의 네 면 관찰은 기존 정책이 우선한다.

## 검증

- VM의 별도 ROS 작업공간에서 `osp_mission` 빌드 및 Mission/Hybrid import 성공. 합성 불규칙 L자 물체에 대한 짧은 정면 관찰, 추가 관찰 목표, 차단/기시야 거부 검사 4개 통과.
- 최근 실물 실행 `20261119T110237-11c9096872`의 **저장된 결정 지도 40장에만** 카메라 위치를 로봇 위치로 근사하고 199.255px 초점거리·1.12rad 시야를 적용했다. 기존 관찰 후보 2장, 새 후보 29장, 그중 정면 대기 후보 15장이다. 정책 기록을 매 지도에서 초기화했으므로 실제 관찰 횟수·성공률·주행 시간은 이 숫자로 추정할 수 없다. 카메라 외부 보정과 동적 지도 변화도 반영하지 않은 정적 비교다.
- 실물 주행 및 새로운 마커 발견률·충돌 횟수는 미측정이다. 출발 명령은 실행하지 않았다.

## 실행

`stage.py`로 기존 `flow_v3_r32_side_ws/src/osp_mission/osp_mission`에서 후보를 생성하고 `stage_workspace.py`로 별도 작업공간에 복사한다. `colcon build --packages-select osp_mission --symlink-install` 후 `test_general_surface.py`로 확인한다. 준비 상태만 보는 명령은 `./robot.sh check-general`, 명시적 실물 출발은 `./robot.sh start-general` 또는 보드의 **Mixed · 일반 장애물 집중 탐색** 버튼이다.
