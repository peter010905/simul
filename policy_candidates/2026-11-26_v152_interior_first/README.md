# Mixed v1.5.2.45 가운데 박스 우선

부모는 v1.5.2.44의 LiDAR 5m 사본이다. 기존 실물 정책을 보존한 별도 실험판이며, 원래 사진의 위치나 지도 좌표를 정책에 저장하지 않는다.

## 목표 선택 순서

1. 등록된 ID 접근과 실제 마커 재관찰은 기존 Mission의 우선 처리를 따른다.
2. 기록된 작은 벽 후보, 거리 없는 ID 방향, 먼 마커 단서에 안전한 관찰점이 있으면 먼저 확인한다.
3. 중단된 박스 면과 진행 중인 박스의 안전한 남은 면을 기존 55초 예산과 재개 제한 안에서 이어 본다.
4. 가까운 확인된 박스의 미관찰 면을 선택한다. 후보는 기존 SLAM·전역·지역 장애물 지도와 시야 검사를 통과해야 한다.
5. 내부 표면과 미탐색 공간을 평가한다. 실제 관측된 벽 표면에서 더 떨어진 Frontier에 완만한 가산점을 주고, 이동 경로 비용과 방문 기억을 반영한다.
6. 유용한 내부 작업과 미탐색 공간이 없으면 기존 벽 관찰로 추가 관측 기회를 확보한다.

벽은 일반적인 카메라 관찰 목표가 자동으로 내부 작업을 이기던 부분을 조정했다. 마커의 존재를 전제로 전체 벽을 영구 제외하지 않는다. 벽 단서가 있어도 안전한 관찰 위치가 없으면 이동을 보류한다.

## 박스와 책상 다리

기존 다각도 관찰점 생성, 중단된 면 재개, 안전 우회 거리로 면 순서 선택, 관찰 완료 판정, 작은 장애물 필터를 재사용한다. 흰색이 대응된 작은 책상 다리의 후보 기억도 이어진다. 주행 중 카메라에 들어온 벽과 내부 표면의 관찰 상태는 기존 실제 영상 처리 경로에서 함께 갱신된다.

지도에서 확인한 벽 표면에 대한 거리 가산은 정보량과 경로 비용에 곱하는 부드러운 선호이다. 사진 중심점, 미지 영역 경계, 고정 동서남북 좌표를 목적지로 지정하지 않는다. 잘못된 내부/벽 분류와 지도 공백은 여전히 성능에 영향을 줄 수 있다.

## 검증 결과와 범위

정책·검출·재개·회전 관련 검사 55개와 보드 검사 61개를 통과했다. 실제 CenterWall 선택 함수에 벽 후보를 주입한 검사에서, 로컬 박스 작업보다 벽 마커 단서가 우선함을 확인했다.

실물 주행 20261125T174857-2f02f6e167의 같은 SLAM·전역·지역 장애물 지도·처리된 CameraInfo 10개 시점에서 부모와 수정판을 비교했다. 저장된 작은 벽 후보와 거리 없는 ID 방향도 재생했다.

- .44는 벽 표면 9곳과 내부 표면 1곳을 선택했다.
- .45는 내부 표면 7곳, 내부 Frontier 1곳, 벽 후보 2곳을 선택했다.
- 실제 상자가 선택됐던 4개 시점에서는 .45가 모두 해당 상자의 관찰점을 선택했다.
- 벽을 선택한 두 시점의 이유는 wall_marker_evidence였다.

이 비교는 당시 선택됐던 상자의 중심만 주입해 일반 면 후보를 재생했다. 다른 객체 추적 상태와 방문 기억은 빈 상태로 시작했고, 작업 재개 기능을 중립화해 목표 선택부를 비교했다. 따라서 실제 부모 주행을 완전히 복원한 결과가 아니며, 마커 성공률·충돌·전체 시간을 직접 비교하는 자료로 사용할 수 없다.

좌표 변환 기록이 없는 시점은 0.15초 이내 정책 자세와 odometry를 맞췄다. 실제 Nav2 경로 계획 Action과 새 실물 주행은 미검증이다. 21cm 출발 여유처럼 안전 마스크에서 모든 경로가 차단되는 기존 상황은 이번 목표 우선순위 변경으로 해결됐다고 볼 수 없다.

실물 보드의 새 이름은 Mixed v1.5.2.45 · 가운데 박스 우선 · LiDAR 5m (실험)이다. 원래 .40·.44 선택지와 12m 사본도 보존한다.
