# 반복 인쇄 단서 재생 비교

Mixed v1.5.2.1로 기록한 분산 배치 세 주행의 6,222장에 같은 판정을 적용했다. 5~18px 미만의 잠정 판독이 1초 안에 서로 다른 프레임 세 장에서 일치해야 한다. 같은 ID가 이미 등록된 뒤의 관측은 제외했다. 지도용 후보는 촬영 당시까지 저장된 점유 지도에서 벽 형태를 확인한다. 방향만 다시 보는 후보는 odom에서 방향 편차 5도, 촬영 위치 변화 35cm 이내를 요구한다. 지도와 정답 위치를 대조하는 평가는 후보 생성이 끝난 뒤에 수행했다.

| 배치 | 방향 재관찰 제안 | 실제 마커 방향과 일치 | 지도 기반 벽 재방문 제안 |
| --- | ---: | ---: | ---: |
| 1398584497 | 2 | 2 | 0 |
| 550866253 | 4 | 4 | 1 |
| 417608489 | 2 | 1 | 0 |

마지막 배치의 서쪽 768번 방향은 111.292초에 잡혔다. 이 배치에는 인쇄되지 않은 382번 방향 제안도 1회 있었다. 세 배치의 실제 정책 로그에서 원거리 힌트로 선택된 목표는 0개였다. 지도 기반으로는 북쪽 418번에 대해 210.076초에 재방문 요청이 가능했고 추정 위치 오차는 0.15m였다. 같은 잠정 ID의 방향을 90초 후 다시 제안할 수 있어 347번을 두 번 센다.

처음부터 끝까지 같은 녹화 경로로 재생했다. 방향 제안이 실제 회전·판독·접근 성공으로 이어지는지, 다른 목표를 미루는 비용이 얼마인지는 측정할 수 없다. 세 번째 주행은 문제를 발견한 개발 사례다. 실물 제어 메뉴에는 이 실험을 추가하지 않았다.

재생 시 ROS Jazzy와 설치된 Focus Continuity 오버레이를 활성화하고 기존 range_replay.py와 balanced_print 모듈을 PYTHONPATH에 둔다. replay.py에 보드 녹화 상위 폴더, 회차별 센서백 상위 폴더, 출력 JSON 경로를 순서대로 전달한다. [프레임·요청 결과](result.json)
