# Flow v3 벽·장애물 면 재관찰 실험

11월 18일의 같은 주행 기록에서 기존 정책이 고른 목적지와 새 규칙이 고를 목적지를 비교했다. ROS 기록 파일만 읽는 오프라인 후보이며 로봇 제어기를 호출하지 않는다.

## 무엇을 기억하는가

카메라 시야에 들어온 연속 라이다 반사점 5개로 짧은 면을 추정한다. 로봇의 주행 좌표계에 면의 위치와 카메라 쪽을 향한 법선을 저장한다. 20cm 이내이고 법선이 약 35도 이내인 관측을 묶는다. 한 프레임에서 같은 면을 여러 번 맞혀도 한 번만 센다. 장애물의 반대쪽은 별도다.

카메라 보정값과 거리를 이용해 8cm 인쇄물이 해당 각도에서 최소 18픽셀로 보일지 추정한다. 프레임 가장자리, 비스듬한 각도, 작은 예상 크기, 심한 노출, 낮은 영상 세부량 중 하나라도 있으면 약한 관측이다. 같은 방위의 영상 가운데 높이 60%를 사용하므로 흰 벽 자체도 낮은 세부량으로 분류될 수 있다. 실제 인쇄물의 위치·크기·높이는 판정에 주어지지 않는다. 1.5초 안에 약한 관측이 두 번이면 저장하고, 양호한 관측이 두 번이면 해제한다. 다른 시점에서 재관찰했다는 집계에는 최초 저장 뒤 3초 이상, 관찰 위치 이동 30cm 이상을 요구했다.

## 다시 볼 위치를 고르는 방법

당시 지도와 로봇 자세를 이용해 저장한 위치를 지도 좌표에 맞춘다. 점유 칸이 같은 방향의 빈 칸과 이웃하는지 다시 확인한다. 최근 120초 안에 약하게 본 면만 고려한다. 기존 목적지와 예정 회전으로 확인 가능하면 원래 선택을 유지하고, 기존 목적지에서 각도만 바꿔도 보이면 방향만 제안한다. 이동이 필요하면 당시 계획기가 이미 생성한 후보 중 가시선이 열리고 정면에 가까우며 예상 크기가 충분한 지점을 고른다. 당시 계획 거리 증가를 1m로 제한하고, 전체 제안 사이는 45초, 같은 방향의 80cm 이웃은 90초 동안 다시 제안하지 않는다. 마커 추적이 우선인 결정은 비교에서 제외한다.

## 재현

기존 Flow v3 surface sweep의 ROS 2 Jazzy 환경을 불러온 상태에서 후보 폴더의 다음 명령을 사용한다. 입력은 각 주행의 rosbag과 artifacts/policy_decisions이다. 시간은 각 로그의 미션 시작을 기준으로 한다. 지도·센서·이전 제안만 목적지 결정에 쓰며, 마커 좌표와 ID는 결과 대조에만 사용한다.

```sh
python3 -m unittest -v test_surface_memory
python3 replay.py OUTPUT_DIR RUN_DIR_1 RUN_DIR_2 RUN_DIR_3 RUN_DIR_4
```

각 실행의 세부 출력에는 면의 위치·방향과 판단 이유, 당시 원래 목적지, 재관찰 제안 좌표·방향, 기록된 이동 경로가 담긴다. results.json에는 주행별 집계를 담았다.
