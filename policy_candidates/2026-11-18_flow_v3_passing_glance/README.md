# Flow v3의 짧은 마커 재관찰

17:37 주행에서 7번의 흑백 인쇄면이 보이던 25.061초에 기존 가장자리 후보는 0.50초 정지 관찰을 요청했다. 개선판은 같은 프레임에서 오른쪽 3.14도 회전과 0.60초 관찰을 요청했다. 녹화의 첫 ID 판독은 33.061초였다. 회전 뒤 새 카메라 화면이나 판독 시각은 이 녹화에서 측정할 수 없다.

여러 프레임에서 같은 면의 인쇄 테두리가 이어지고 기존 제안이 정지 관찰일 때 보정된 화면 방위를 사용한다. 중앙에서 2도 이상 벗어난 인쇄면은 최대 6도까지 다시 조준한다. 기존 여러 프레임 회전은 종전 각도를 사용한다. 한 프레임만 보이는 가장자리 후보는 주변 작은 영역에서 검은 테두리와 Original 계열의 5×5 행 무늬를 확인한다. 한 칸 차이를 허용하며 ID를 결정하지 않는다. 기존 1.79배 가로 초점거리 보정과 시간·공간 중복 억제를 사용한다. 평가용 모듈은 실물 동작 명령을 보내지 않는다.

## 같은 영상에서의 비교

17:37만 개발에 사용했다. 비교 방식은 직전 단일 프레임 후보이다. 아래 시각은 동기화된 영상에서 사람이 마커 위치까지 확인한 첫 재관찰 요청이다. 실제 회전 실행 시각과 구별한다.

| 주행 | ID | 기존 요청(초) | 개선 요청(초) | 녹화 첫 판독(초) |
|---|---:|---:|---:|---:|
| 17:37 | 7 | 25.061 정지 | 25.061 회전 | 33.061 |
| 전날 22:19 | 103 | 21.586 회전 | 21.686 회전 | 21.686 |
| 12:58 | 7 | 208.723 회전 | 208.723 회전 | 208.723 |
| 16:40 | 7 | 121.808 회전 | 121.913 회전 | 123.109 |
| 17:08 | 103 | 111.126 정지 | 111.126 정지 | 112.224 |
| 17:23 | 7 | 201.172 회전 | 201.274 회전 | 201.373 |

평가용 14개 주행은 이전 실험에서도 평가에 썼고 이번 규칙 조정에는 사용하지 않았다. 12,298개 동기화 프레임에서 7번·103번의 18픽셀 이상 판독은 없었다. 실제 목표에 대한 민감도는 이 집합에서 추정할 수 없다. 기존 회전 요청 13회는 배경 7회, ID 미확인 인쇄물 4회, 다른 사전 표식 1회, 불명확 1회였다. 개선판은 소화기 안내판에 1회 회전을 요청했다. 기존에는 이 안내판을 향해 정지 관찰을 요청했다. 개선판이 없앤 회전 중에는 표식처럼 보인 인쇄물을 향한 네 번도 들어 있다.

## 처리 시간과 관찰 시간

Mac의 기존 Ubuntu VM에서 OpenCV 한 스레드로 250×250 영상과 라이다를 재생했다. 프레임마다 공통 테두리·면 추적을 한 번 수행한 뒤 구·신 결정에 같은 결과를 제공했다. 홀드아웃 주행마다 최초 10프레임을 시간 집계에서 제외했다. 12,158프레임에서 기존 재관찰 계산 평균 0.775ms, 개선판 0.776ms였다. 두 방식 모두 ID 판독을 더하면 평균 3.23ms, 95백분위 5.12ms였다. 재생 파일 읽기, ROS 전송·스케줄링, 지도 등록, 모터 응답은 측정 범위 밖이다.

정지와 회전을 포함한 명시적 관찰 대기 요청의 합은 14개 주행에서 5.9초에서 2.4초로 줄었다. 이는 회전·가감속·경로 재개를 포함한 실물 소요 시간이 아니다.
