# 벽면의 ArUco Original 마커 판독 보완

17시 08분 실물 주행 `20261118T080829-46b72fd54a`의 OAK-D 영상에서 벽의 표식을 확인했다. 기존 실물 인식기는 1,814프레임을 처리해 판독 0회였다. 약 125초의 영상에서는 OpenCV가 바깥 사각형을 찾았지만 내부 격자의 오른쪽 칸이 압축돼 균일 격자 샘플링으로 ID가 나오지 않았다.

Flow v3의 인접 마커 판독을 먼저 적용한 뒤, 탈락한 사각형 중 원본에서 변 길이 18픽셀 이상인 후보만 재검사한다. 원근을 보정한 영상에서 한 축의 칸 간격을 조금씩 바꿔 Original 사전 전체와 대조한다. 검은 테두리를 포함한 패턴이 정확히 맞고 방향과 ID가 하나로 정해질 때만 결과를 넘긴다. 기존 거리 검증과 다중 프레임 확정 절차는 그대로 적용한다.

17시 08분 기록에서 보정 전 목표는 0개였다. 재생 수치는 영상 판독 결과이며 거리 검증·지도 등록·실제 접근은 새 실물 주행에서 확인해야 한다. 벽면 주행 재생의 인식기 처리시간 95백분위는 3.8ms였다. 정책 검사 394개와 보드·실행기 검사 30개를 통과했다.

보드의 **Flow v3 · MPPI 구동**과 `./robot.sh start-v3-mppi`가 `face_intent_v3_warp_ws`를 선택한다. 이 작업 공간에서 이전 후보의 `replay.py`에 원본 주행 디렉터리를 전달하면 같은 영상 판독 결과를 확인할 수 있다.
