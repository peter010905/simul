## 적용한 동작

범퍼 입력이 풀린 뒤 0.5초간 기다린다. 후방이 확보되면 Nav2에 12cm 후진을 요청하고, 이어 접촉 반대쪽으로 65° 회전을 요청한다. 후진을 생략하거나 후진이 실패해도 회전에 성공해야 전진 계획을 재개한다. 회전이 막히면 정지하고 후방을 다시 확인한다. 오래된 범퍼 신호에서는 다음 복구 동작을 시작하지 않는다.

기존 마커 방향·지도 기반 관측을 우선하고, 출발 시 지도상 관측각이 0°이면 45°를 본다. 이후 마지막 관측에서 25초가 지나고 2m 이상 떨어진 경우 관측 기회를 만든다. 거리 없는 동일 ID가 가까운 화면 방향에서 세 번 연속 관측되면 해당 방향을 바라볼 수 있다. 위치 등록·근접 완료에는 기존 거리 증거가 필요하다. 일반 추적 목표는 1초 안에 위치가 30cm 이내로 일치하는 두 개의 서로 다른 거리 관측을 요구한다. 즉시 실패한 주행 목표의 다음 시도에는 2초를 둔다.

## 검증

- 저장 영상에서 새 방향 판정을 재생했다. 42의 세 프레임은 각각 16.25°, 17.61°, 18.63° 왼쪽이었고 세 번째에 한 번 관측 신호가 발생했다. 단일 0 관측은 추적 목표 조건을 충족하지 않는다.
- 격리된 Gazebo에서 주행 중 왼쪽 범퍼 신호를 한 번 주입했다. 목표 취소, 후진 실패, 오른쪽 65° 회전 성공, 새 목표 진입을 확인했다. 50초간 5.03m 이동했고 시작 관측 45°와 이후 지도 기반 관측 105°도 수행했다. 물체와의 실제 충돌을 재현한 시험은 아니다.
- 정책 테스트 389개 및 보드 제어·실행기 검사 30개 통과. 실물에는 구동 버튼과 셸의 작업 공간만 갱신했다. 개선판의 실물 접촉 횟수와 마커 완주율은 미측정이다.
