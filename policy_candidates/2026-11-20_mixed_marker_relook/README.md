# Mixed v1.2 · 판독 마커 재관찰

실물 대시보드에 있는 두 선택지는 같은 검출기와 재관찰 정책을 사용한다. 기본 재관찰판의 MPPI 전진 상한은 0.25 m/s이고 속도 제한기 상한은 0.27 m/s이다. **0.45 m/s** 버튼은 두 전진 상한을 모두 0.45 m/s로 설정한다. 개별 주행의 최종 Nav2 설정은 해당 결과 폴더의 `artifacts/nav2_forward_045.yaml`에 기록한다. 원래의 상자 재방문 줄이기 v1.1도 계속 선택할 수 있다.

## 실물 녹화 재생

| 녹화 | 처리한 영상 | v1.1 등록 ID | v1.2 등록 ID |
| --- | ---: | --- | --- |
| 11월 20일 16:41 시작 | 2,612프레임 | 없음 | 5 |
| 11월 20일 15:39 시작 | 2,413프레임 | 42 | 42 |

16:41 실물 주행은 발견 0개로 끝났다. 5번은 영상에서 28번 판독됐지만 실시간 기록에서 거리 없음 21회, 위치 불일치 6회, 유효한 위치 1회였다. 등록에는 일관된 위치가 세 번 필요했다. 수정판으로 같은 영상을 재생했을 때 16:45:13.65에 5번 방향을 재관찰 대상으로 보냈고, 16:45:36.84에 두 번째 관측 위치에서 등록 기준을 통과했다. 대시보드용 목표 메시지에도 5번이 들어갔다. 이 녹화에는 지도와 오도메트리를 연결하는 변환이 없어 두 버전 모두 오도메트리 좌표로 비교했다. 절대 지도 위치의 정확도, 재관찰로 실제 경로가 바뀌는 효과, 실물 1.5 m 접근과 최고속도는 별도 주행에서 측정해야 한다.

15:39 녹화에서는 두 버전 모두 지도 좌표로 42번만 발행했다. 새 버전은 0번도 한 차례 재관찰 대상으로 올렸다. 0번은 최종 등록에 이르지 않았다. 이 기록으로 실제 헛회전 횟수를 측정할 수는 없다.

## 바뀐 동작

- 기존 크기·품질 검사를 통과한 ID가 일관된 방향에서 세 프레임 반복되면 대시보드에 판독 ID를 표시한다. 촬영 당시 카메라 자세도 확보되면 진행 중인 일반 탐색이나 면 관찰을 잠시 멈추고 그 방향을 다시 본다. 충돌 복구와 이미 등록된 마커에 대한 접근이 우선한다.
- 두 위치에서 같은 번호를 여러 프레임 읽으면 카메라 방위로 거리를 추정한다. 시점 간격 0.35 m 이상, 시차각 12~145도, 두 시점의 크기·방향 일치 검사를 통과해야 한다. 깊이가 없고 LiDAR가 거리를 주지 못하거나 등록 전 LiDAR 위치가 여러 시점의 결과와 충돌할 때 이 추정을 사용한다. 위치 등록에는 기존 합의 기준을 적용한다.
- 실물 대시보드의 카메라 판독, 지도 등록, 접근 완료는 따로 집계된다. 기존 충돌 감시, 범퍼, 회전·후진·가감속 설정은 두 속도판에서 동일하다. 최종 런치 비교는 전체 Nav2 설정 중 MPPI의 `vx_max`와 속도 제한기의 `max_velocity[0]`만 달라지는지 검사한다.

## 설치와 재현

준비된 v1.1 워크스페이스가 있는 Jazzy VM에서 저장소 루트를 기준으로 실행한다. 설치는 새 경로를 사용한다.

```sh
source /opt/ros/jazzy/setup.bash
candidate="$PWD/policy_candidates/2026-11-20_mixed_marker_relook"
python3 "$candidate/install.py" ~/flow_v3_r32_cluster_exit_ws ~/flow_v3_r32_marker_relook_ws
cd ~/flow_v3_r32_marker_relook_ws
colcon build --packages-select osp_mission
source install/setup.bash
export ROS_DOMAIN_ID=182 ROS_LOCALHOST_ONLY=1
python3 -m pytest -q "$candidate/test_marker_relook.py" "$candidate/test_forward_profile.py"
python3 "$candidate/replay.py" "$BAG_PATH" /tmp/replayed_ids.json
```

기존 결과를 재현할 때는 새 셸에서 v1.1 워크스페이스를 로드하고 같은 격리 도메인에서 같은 녹화를 사용한다. 재생기는 당시 처리한 영상 시각, 원본 스캔, 카메라 정보, 촬영 시점의 자세를 사용한다. 로봇에 목표나 속도 명령을 보내지 않는다.
