# Mixed v1.5.2.18 · 선택한 이동 유지

.17의 시험장에서 미탐색 구역으로 이동하던 Nav2 목표가 `inspection_due`로 취소됐다. `ContactInspection.due()`의 25초·2m 주기 관찰이 주행 중 관찰 비활성 설정과 별도로 실행되고 있었다. 취소 뒤에는 회전한 후 원래 목표를 보관하지 않고 다시 탐색 목표를 결정했다.

이 후보는 주행 중 관찰이 꺼져 있으면 이동 중인 Nav2 목표를 **주기 관찰이나 일반 벽 훑기 때문에 취소하지 않는다**. 안정적인 새 마커 방향, 확인할 마커 ID, 범퍼, 센서 이상 및 실제 정체는 기존 우선 경로를 사용한다. 도착 후의 카메라 관찰과 지도 갱신도 계속 실행한다.

```sh
python3 policy_candidates/2026-11-24_v152_finish_transit/install.py \
  ~/v152_focus_continuity_box1122_ws ~/v15218_finish_transit_640_1124_ws
```

시험에서는 640×480·5fps, 같은 시험장 시드에서 이동이 진행되는 첫 구간을 확인한다. 짧은 시험 결과는 600초 완주 결과와 섞지 않는다.
