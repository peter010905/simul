# Mixed v1.5.1-rescue360

원본 v1.5.1-balanced를 기반으로 만든 별도 시뮬레이션 후보다. 앞의 360초는 기존 탐색 선택을 사용한다. 이후에는 벽과 장애물의 단계 우선순위를 우회하고 전 방향 정보 이득으로 목표를 고른다. 등록한 마커의 근거리 확인과 판독 중인 ID는 기존 경로로 처리한다.

## 목표 선정

기존 edge_policy.options의 full_scans=True를 사용해 한 자리에서 360도 관찰할 때 카메라로 새로 볼 수 있는 표면 길이를 계산한다. 기존 촬영 시각·TF·LiDAR 교차점으로 확인한 면은 제외한다. 카메라 거리·입사각·시선 가림 검사와 기존 판독 크기 사전조건을 재사용한다. SLAM에서 새로 드러날 수 있는 미지 공간 이득도 함께 계산한다.

기존 가중치의 표면 이득과 미지 공간 이득을 합산한다. 기존 안전 격자 후보, Nav2 costmap 연결성, 최근 실패 위치 제외 조건과 시간 예산을 통과한 후보 중 이 합이 가장 큰 지점을 선택한다. 동점은 격자 경로 거리가 짧은 후보를 선택한다. 단순 지도 확장 이득만으로 벽 표면을 제외하지 않는다.

Nav2 global costmap이 없거나 오래됐으면 이 모드의 일반 이동 목표를 보내지 않는다. 새 마커 ID를 확인하는 기존 직접 접근은 기존 검사 경로를 사용한다. 도달 가능성은 기존 격자 연결성과 실행 시 Nav2 경로 계획을 사용한다. 사전 이동 시간은 격자 경로 길이로 근사한다.

## 360도 관찰과 예산

실제 mission/start 이후의 경과를 기준으로 6분 전환을 판단한다. 일반 이동 중이면 기존 액션 취소 응답을 받고 다시 계획한다. 이미 수행 중인 회전·안전 복구·확인된 ID 접근은 처리 후 전환할 수 있다.

이동 시간과 360도 회전, 가감속, 촬영 대기 및 3초 여유를 함께 계산한다. 회전 상한 0.5rad/s·가속도 1rad/s²에서 이상적인 한 바퀴 회전은 약 13.07초이고, 촬영 대기 1.5초와 여유를 더하면 이동을 제외한 예산은 약 17.57초다. 실제 주행·회전이 이 근사보다 오래 걸리면 기존 임무 제한 시간에 종료할 수 있다.

도착하면 Nav2 Spin에 2π를 요청하고 기존 충돌 검사를 사용한다. 실제 회전 피드백이 한 바퀴에 가까워야 하며, 그동안 실제 촬영 시각에 유효한 카메라 관찰 갱신도 3회 이상 있어야 완료 회전으로 기록한다. 촬영 대기 동안 갱신한 관찰 지도로 다음 위치를 다시 평가한다. 완료한 지점 반경 1.25m는 같은 임무의 일반 전 방향 탐색에서 제외한다.

센서 끊김으로 회전이 중지되면 기존 미션의 남은 각도 복구를 사용하며 회전량을 누적한다. 새 ID의 판독·접근으로 중지됐거나 짧은 회전만 마쳤으면 360도 완료로 기록하지 않는다. Nav2 실패 지점은 기존 실패 제외와 추가 45초 유예를 적용한다.

## 설정과 기록

| 파라미터 | 기본값 | 의미 |
|---|---:|---|
| rescue_after_s | 360 | 전환 시각, 임무 경과 초 |
| rescue_travel_speed | 0.20 | 격자 이동 시간 추정 속도 m/s |
| rescue_spin_rate | 0.5 | 회전 시간 추정 상한 rad/s |
| rescue_spin_accel | 1.0 | 회전 가속도 추정 rad/s² |
| rescue_settle_s | 1.5 | 회전 후 영상 대기 초 |

추정 회전 속도·가속도는 원본 동결 Nav2 프로필의 값과 일치한다. 실제 제어 속도·충돌 감시·footprint·inflation·마커 18px·합의·근거리 접근 기준은 원본 설정을 사용한다.

rescue360.jsonl에 전환, 선택 목표, 카메라·미지 공간 이득, 예상 시간, 도착, 회전 요청, 실측 각도, 유효 촬영 갱신 수와 성공·실패를 남긴다. 전체 표면을 봤다는 뜻으로 회전 완료를 사용하지 않는다.

## 검증

6분 이전 동작 보존, 마커 접근 보호, 미지 공간 이득 0인 카메라 표면 목표, 이동·회전·가감속·대기 예산, 부분 회전·센서 복구, 실제 전 방향 후보 생성과 기존 안전·접근 검사를 포함해 52개 검사가 통과했다. 이동 중 벽 관찰 플래그에 관한 기존 검사 1개는 원본에서도 동일하게 실패한다.

Ubuntu Jazzy에서 원본 소스·설정 해시를 확인한 후 새 작업공간에 설치한다.

```bash
python3 policy_candidates/2026-11-21_v151_rescue360/install.py \
  policy_releases/2026-11-21_mixed_camera_sync_v151 ~/flow_v151_rescue360_r2_ws
cd ~/flow_v151_rescue360_r2_ws
source /opt/ros/jazzy/setup.bash
colcon build --symlink-install --packages-select osp_mission
```
