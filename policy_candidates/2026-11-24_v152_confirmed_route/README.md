# Mixed v1.5.2.28 · Confirmed Route

[On-site Visit](../2026-11-24_v152_onsite_visit/README.md)의 일반 상자·벽 관찰과 같은 ID 집중 재관찰을 이어받는다. 시험에서 알려 준 개수만큼 ID를 전부 등록했고 근접 증거가 남았다면, 마지막 마커를 실제로 본 쪽으로 우회할 수 있는지도 확인한다.

시드 2248916956에서 .27은 102번을 444.264초에 등록하고 453.828초에 실제 1.5m 안으로 들어갔다. 이때 측정 증거를 얻지 못했고 599.772초에야 근접을 확인했다. 등록 직후 444.792초 결정의 저장 SLAM 지도를 재생했다. 당시 등록 좌표와 마지막 카메라 관측 위치를 사용하면 기존 15개 관찰점 중 직선이 허용된 곳은 0개, 보행 경로와 표면 시야가 있던 곳은 10개였다. 가장 짧은 예상 경로는 3.05m였다. 재생에는 당시 Nav2 비용지도가 없어, 실제 우회 허용 여부는 폐루프 시험에서 별도로 기록한다.

- 일반 접근 목표가 유효하면 기존 방식대로 수행한다. 직접 접근이 성립하지 않을 때는 동일한 인쇄면의 0.75·0.85·0.90m 관찰점을 재사용한다. SLAM의 0.32m 여유, Nav2 비용지도, 연결 경로, 촬영 방향, 실패 목표 제외를 적용한다.
- 등록 직후 이미 갖고 있던 거리·시간·촬영 조건을 사용한다. 남은 시간 또는 Nav2의 65초 동작 제한에서 촬영 8초를 제외해 예상 이동 예산을 계산한다. 같은 ID에 우회는 두 번까지, 두 번째에는 다른 각도를 시도한다. 시도는 목표를 실제로 보낼 때 기록한다.
- 근접 확인은 기존 센서 로직이 담당한다. 눈앞을 통과했거나 경로가 생성된 것만으로 완료되지 않는다. 새로운 지도나 하드웨어 제어 노드를 추가하지 않는다.
