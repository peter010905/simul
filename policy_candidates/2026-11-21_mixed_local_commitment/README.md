# Mixed v1.6.0 · 가까운 미관찰 면과 마커 focus 조정

v1.5.1의 센서 동기화를 유지하고, 미확인 마커 focus가 상자 관찰 스케줄을 무조건 우회하던 부분을 제한적으로 조정한다. 첫 평가의 112101 회차에서는 상자 면이 남아 있는데 먼 벽 7번 focus가 먼저 선택돼 나중에 상자로 돌아왔다. 이 맵은 이제 튜닝 자료이며 최종 평가용 새 맵과 구분한다.

- 이미 확인한 마커 접근과 충돌·센서·범퍼 복구는 우선한다. 미확인 focus만 조정한다. 가까운 증거나 현재 물체 자체의 마커 단서는 미루지 않는다.
- 현재 관찰 중인 물체의 안전하고 새로운 면이 실제 기존 계획기에서 나올 때만 그 면 하나를 먼저 선택한다. 동일 물체·근접 거리·이전 시도 없음·미완료·남은 시간 조건을 모두 검사한다. 정답 장면이나 마커 위치는 사용하지 않는다.
- 한 물체에서 120초 동안 한 번만 추가 관찰한다. 20초 예산을 0.5초마다 검사하며, 초과하면 기존 marker_hint 취소·재계획 경로로 기억한 단서에 양보한다. 취소 응답 지연과 안전 복구 시간은 별도다. 복구 중 강제 취소하지 않는다.
- `MarkerFocus.choose`의 제안과 실제 실행을 분리한다. 다른 confirmed approach가 선택돼 focus를 실행하지 않았다면 시도 횟수·30초 대기를 소모하지 않는다. 제안과 dispatch 로그도 구분한다.

Nav2·footprint·inflation·속도·18px·세 프레임 ID 합의·1.3m 근거리 영상 증거는 보존한다. 추가 관찰점은 기존 지도·costmap·경로 필터를 통과해야 하며 실제 이동은 그대로 Nav2 Action이 판단한다.

전체 수정판의 회귀 검사 44개를 통과했다. [소스 해시](source_manifest.json), [원인별 주행 비교](../../experiments/2026-11-21_camera_aware_policy/README.md).

개발 맵 두 회차는 모두 과제를 통과했지만 평균 93.3초로 v1.5.1의 83.9초보다 느렸고, 추가 면 관찰 dispatch가 실제로 발생하지 않았다. 이 표본에서 상자 우선 관찰의 효과를 확인하지 못했다. 비교 전에 정한 기준에 따라 v1.5.1을 다음 검증 대상으로 골랐으며, v1.6.0은 선택 가능한 실험판으로만 보존한다. 이 판의 미사용 맵 완주율은 측정하지 않았다.

동결 스테이지: `flow_v16_local_commitment_r3_ws`. 비교 버전은 `v1.6.0-detail`(640×640·5FPS)이며 `./sim-camera.sh v1.6.0-detail 112201`로 시뮬에서 선택한다. 기존 버전은 모두 보존한다.
