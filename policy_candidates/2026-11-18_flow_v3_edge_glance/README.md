# 화면 가장자리 한 프레임 재관찰

기존 두 프레임 정책과 같은 테두리 검출기, 원거리 면 연결, 1.79배 가로 각도 보정, Original 18픽셀 판독기를 사용했다. 좌우 바깥 20%에서 검출한 테두리 하나로 최대 6도 회전 및 0.30초 관찰을 요청한다. 거리가 없는 단서도 방향만 사용한다. 직전 요청 후 12초, 가까운 위치에서 비슷한 방향의 단일 프레임 요청 후 90초 동안 중복 요청을 제한한다. 0.30초 안에 발생한 다음 요청은 별도 회전으로 세지 않는다. 실물 주행에는 배포하지 않았다.

## 평가

새 규칙·로그 선정·판정 조건을 먼저 고정해 frozen.sha256에 기록했다. 이전 마커 실험에서 언급된 로그를 제외한 주행과, 과거에 살펴본 목표 사례를 구분했다. 같은 카메라 프로필을 가진 미사용 전체 녹화에서 19,352프레임을 검사했으나 7번·103번의 유효 18픽셀 판독이 없었다. 센서가 동기화되고 미션 시작·종료가 확인된 새 기록은 14회, 12,298프레임이었다. 이 집합에서 목표 판독에 대한 선행 성공률은 구할 수 없었다.

| 영상에서 재확인한 사례 | 기존 두 프레임 회전 | 한 프레임 회전 |
|---|---:|---:|
| 11/17 22:19, ID 103 | 첫 판독과 동시 | 0.100초 전 |
| 11/18 12:58, ID 7 | 0.097초 후 | 첫 판독과 동시 |
| 11/18 16:40, ID 7 | 1.196초 전 | 1.300초 전 |

이 세 사례는 이번 규칙을 고정한 뒤 재생했지만 이전에 검토한 자료다. 표는 영상 속 마커를 향한 회전 제안 시각이다. 첫 사례의 제안 위치는 기록 좌표와 11.5cm 차이였다. 두 번째 사례는 55.4cm였고 세 번째 사례에는 기록 기준 좌표가 없었다. 판독과 같은 프레임의 반응은 조기 반응에 포함하지 않았다.

미사용 주행에서 실제로 발생한 회전 제안은 기존 0회, 후보 13회였다. 두 방식의 전체 회전 장면을 정책명이 가려진 순서로 검토했다. 후보 13회 중 7회는 창틀·의자·벽·문패 등 명백한 배경이었다. 1회는 4×4 사전으로 읽힌 다른 표식, 4회는 표식 형태지만 ID를 확인하지 못한 대상, 1회는 불명확했다. 따라서 목표와 무관한 회전은 최소 8회였다. 이전에 검토한 보조 집합 4회에서는 회전 5→18회, 명백한 배경 회전 0→9회였다. 기록된 카메라 자세를 이용해 선택만 재생했다. 회전 후 새로 보일 장면과 실제 발견 시간은 측정하지 않았다.
