# Mixed v1.5.3 · 구역 전환과 벽 구간 관찰

v1.5.2 r2에서 관찰 위치를 선택하는 부분을 바꾼 별도 시뮬레이션 후보판이다. 새로 생긴 벽 목표도 기존 지도 여유 공간, costmap 연결성, 시선과 실패 목표 필터를 거쳐 Nav2에 전달된다. 카메라는 480×480, 5 FPS로 동작하며 판독과 근거리 확인은 기존 검출기가 담당한다.

- 내부 면을 선택할 때 그 면 주변 2.5m 안의 미관찰 장애물 표면 셀과 방향을 odom 좌표에 저장한다. 다음 선택 때 지도의 점유 상태가 충분히 일치할 때만 같은 셀의 방향별 카메라 관찰 증가량을 계산한다. 짧은 시간에 두 번 0.25m 미만이면 해당 구역에 75초 동안 낮은 우선순위를 준다. 실행된 이동 시간, 중간 카메라 관찰, 도착 후 회전은 이 관찰 구간에 함께 포함될 수 있다.
- 이미 지도에 나타난 벽의 관찰 후보를 같은 점유 성분과 같은 법선 방향으로 모은다. 떨어지거나 꺾인 부분에서 구간을 끊고 한 구간의 길이를 제한한다. 새로 볼 수 있는 벽 길이, 안전 격자 도보 거리와 관찰 예상 시간, 최근 방문, 영상 단서를 이용해 선택한다. 구간 내 관찰을 잠시 이어가고, 조건을 만족하는 벽 후보가 없으면 내부 탐색을 계속할 수 있다. 미관찰 방향에 아직 벽이 없을 때는 저수익 구역 밖의 안전한 기존 frontier도 고려한다.
- 벽 목표를 주기적으로 검토하고, 남은 시간에서 이동·관찰 시간을 뺀 시점이 더 빠르면 그때 검토한다. 일반 내부 이동 중에도 예정 시점이 되면 취소 응답을 받고 다시 계획한다. 확인된 마커 접근, 마커 판독 추적, 충돌 복구는 기존 순서를 따른다. 새로 발견한 상자 면은 기존 면과 위치·법선이 구별되어야 구역 유예 중에도 다시 내부 후보가 된다.
- 지도 비교가 불확실하면 낮은 관찰 이득으로 기록하지 않는다. 점유 격자에서 벽이 조각나면 동일한 물리적 벽도 여러 짧은 구간으로 분리될 수 있다. 벽 인식과 이동 가능성은 실제 센서·Nav2 결과로 확인해야 한다.

## 재현

설치기는 부모 매니페스트의 파일 해시를 검증하고 새 디렉터리에만 소스 트리를 만든다. 부모 작업공간은 [v1.5.2 r2 설치기](../2026-11-21_mixed_wall_transit_v152/install.py)로 재구성할 수 있다.

```bash
python3 install.py ~/flow_v152_wall_transit_r2_ws ~/flow_v153_region_wall_ws
source /opt/ros/jazzy/setup.bash
source ~/flow_v152_wall_transit_r2_ws/install/setup.bash
cd ~/flow_v153_region_wall_ws
colcon build --symlink-install --packages-select osp_mission --executor sequential
```

준비된 Mac에서 `./sim-region-wall.sh 112601`로 첫 맵을 실행한다. `./sim-region-wall.sh all`은 기준 맵 다섯 개를 한 번씩 실행한다. 센서와 주행 전용 도메인은 174이며 임무 제한은 시뮬레이션 시간 600초다. 결과와 평가 기준은 [5맵 비교](../../experiments/2026-11-21_region_wall_v153/README.md)에 기록한다.
