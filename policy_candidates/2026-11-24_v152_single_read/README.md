# Mixed v1.5.2.30 · Single Read

v1.5.2.29 Final Bearing에서 마커 등록과 근접 완료 조건을 분리해 변경한 시뮬레이션 후보이다. 기존 .29 작업공간을 부모로 지정하면 별도 디렉터리에 설치한다.

- ArUco 검출기를 통과한 ID에 대해 해당 영상에 대응하는 깊이 또는 LiDAR 관측점을 촬영 시각의 기체 좌표로 변환한다. 기체 중심에서 마커까지의 수평 거리가 1.50m 이하이면 한 장으로 등록 및 근접 확인이 가능하다. 기록에는 ID, 촬영 시각, 거리, 측정 출처와 기체 기준 좌표가 남는다.
- 시각 후보, 거리가 없는 판독, 여러 시점에서 삼각측량한 위치, 저장된 지도 좌표만으로 근접 완료할 수 없다. 원거리 등록에는 부모 버전의 반복 판독 조건이 적용된다. 서로 다른 ID가 같은 표면 위치에서 충돌하면 기존 ID 구분 절차를 적용한다.
- 영상과 등록 목록은 서로 다른 ROS 토픽으로 도착한다. 같은 프레임의 근접 증거를 저장하고 등록 목록에 ID가 포함되는 즉시 완료에 반영한다. ID가 등록 목록에서 철회되면 해당 증거를 제거한다.
- 시험 정책에는 정답 위치 또는 실제 세계 좌표를 전달하지 않는다. 수평 거리, 지도 저장 오차, 충돌, 잘못 등록한 ID는 독립 채점기가 별도로 확인한다.

## 설치 및 경계값 검사

ROS 2 Jazzy 환경에서 다음 명령으로 .29 소스를 복사하고 새 작업공간을 빌드한다. 설치기는 세 파일의 부모 버전 해시를 검증하고 이미 존재하는 목적지를 거절한다.

```bash
python3 install.py ~/v15229_final_bearing_640_1124_ws ~/v15230_single_read_640_1124_ws
candidate_dir="$PWD"
cd ~/v15230_single_read_640_1124_ws
source /opt/ros/jazzy/setup.bash
colcon build --symlink-install
source install/setup.bash
python3 -m pytest -q "$candidate_dir/test_single_read.py"
```
