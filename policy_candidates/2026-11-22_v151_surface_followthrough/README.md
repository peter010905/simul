# Mixed v1.5.1 surface-followthrough R5

기존 Mixed에서 물체의 한 면에 도착한 뒤 다음 면을 고르는 로직은 짧은 직사각형 상자에 맞춰져 있었다. ㄱ자나 긴 물체처럼 상자 맞춤이 성립하지 않는 경우, 지도에서 같은 독립된 물체로 연결된 다른 면에 잠시 더 머물 수 있게 했다. 원본 balanced, R3와 R4는 각자 선택할 수 있다.

현재 관찰점에 실제 도착하고, LiDAR 점유 셀이 같은 물체로 이어지며, 카메라가 새 표면을 향하는 안전한 후보가 이미 생성돼 있어야 후속 목표가 된다. 벽과 붙어 있거나 둘 이상의 상자와 겹치는 모호한 경우는 보류한다. 한 방문의 추가 목표는 최대 2개, 시간은 최대 30초다. 벽이나 미탐색 구역에 배정한 대기 시간이 먼저 끝나면 해당 목표에 양보한다. 새 목표는 같은 Nav2 경로·충돌 검사와 기존 범퍼 처리를 거친다. 물체 형태, ID, 마커의 정답 좌표를 시뮬레이터에서 읽는 정책 입력은 없다.

R4의 이동 중 작은 RGB 단서 재관찰과 확인된 마커의 접근 절차도 함께 사용한다. 종료 조건의 공개 매개변수 `expected_marker_count`는 과제의 기본값 3이다. 수량을 알려주지 않는 실험은 0으로 설정하며, 이때 3개 도달을 이유로 일찍 종료하지 않는다.

```bash
bash team-sim.sh setup "$HOME/surface-policy" --policy surface-followthrough
```

Jazzy에서 기존 후보와 새 정책의 관련 검사 46개를 통과했다. 이 가운데 새 검사는 ㄱ자 장애물, 물체 혼동, 가림, 벽에 붙은 물체, 시간 제한, 회전된 지도와 부분 지도 좌표, 가변 마커 개수를 다룬다. 건물 일부가 아직 미지 영역과 붙어 있거나 안전한 다음 관찰점이 없으면 한 번의 방문으로 물체를 전부 볼 수 없다. [같은 시험장에서의 실주행 방식 및 결과](../../experiments/2026-11-22_random_exam/README.md)
