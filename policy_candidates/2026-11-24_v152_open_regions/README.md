# Mixed v1.5.2.17 · 미탐색 구역 진입

Stable Survey에서 현 구역에 이어 볼 수 있는 목표가 떨어지면 한동안 주행하지 않은 지역을 다음 선택지로 평가한다. SLAM 미지 영역의 경계 외에, 지도에는 나왔지만 RGB로 읽을 수 있는 방향에서 보지 못한 표면도 대상으로 삼는다.

후보를 고를 때 최근 200초의 오도메트리 궤적과 목표 위치를 비교한다. 최근 경로에서 1.5m 이상 떨어지고, 안전한 예상 경로와 남은 시간 조건을 만족해야 한다. 예상 관찰량과 궤적에서 떨어진 정도를 경로 거리와 비교한다. 이 유형의 이동은 최소 90초 간격이고 남은 시간이 55초 미만이면 시작하지 않는다. 같은 구역에 유효한 관찰이 남아 이어서 수행 중인 경우에는 적용하지 않는다.

```sh
python3 policy_candidates/2026-11-24_v152_open_regions/install.py \
  ~/v152_focus_continuity_box1122_ws ~/v15217_open_regions_640_1124_ws
```

시뮬레이션에서 [.16과 같은 640×480·5fps 시험을 재현](../2026-11-24_v152_stable_survey/README.md)할 수 있다. 새 구역 목표의 이유와 최근 궤적과의 거리, 경로 거리 추정값은 `native/center_wall.jsonl`에 기록한다.
