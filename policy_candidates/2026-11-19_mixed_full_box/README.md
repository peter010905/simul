# Mixed 상자 전면 관찰

현재 Mixed의 마커 판독·접근과 복도 주행을 유지한 별도 빌드 `flow_v3_r32_full_box_ws`다. 실물 보드의 Mixed 버튼이 이 빌드를 선택한다. 기존 `flow_v3_r32_print_ws`는 보존한다.

기존 TwoViews가 서로 다른 LiDAR 시점에서 상자를 확인한 뒤, FullBox는 네 면의 관측점이 지도와 전역 비용지도에서 안전하게 연결되는 경우에만 관찰 목표를 낸다. 모든 관측점은 같은 시작 연결 성분 및 상자 주변 반경 2 m 안의 통행 가능 연결 성분에 있어야 한다. 현재 비용지도가 없거나 한 면의 관측점이 막히면 전면 관찰은 건너뛴다. RGB 프레임에서 실제로 확인한 면은 다시 고르지 않는다. 한 목표를 보냈지만 RGB 증거가 없으면 35초 뒤 다시 시도할 수 있다. 확인된 마커의 접근은 기존 정책이 우선한다. 남은 미션 시간이 45초 미만이면 새 전면 관찰을 시작하지 않는다. 원본 Nav2의 충돌 검사를 유지한다.

`stage.py`는 준비된 `mixed-box-views-v3/osp_mission`에서 후보 모듈을 생성한다. `stage_workspace.py`는 원본 `flow_v3_r32_print_ws`의 ROS 패키지에 그 모듈을 복사한다. 생성한 작업공간에서 `colcon build --packages-select osp_mission --symlink-install`로 빌드한다.

검증은 VM에서 160×160, 5 cm 격자의 독립 상자 모의 지도로 수행했다. RGB 확인을 가정하여 면을 하나씩 기록하면 네 방향을 각각 한 번 선택한 뒤 목표를 내지 않는다. 반대편 경로를 막으면 전면 관찰 목표를 내지 않는다. 이 검사는 실물 주행 결과나 마커 검출률 측정이 아니다.
