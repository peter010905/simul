# 먼 거리의 마커 테두리와 판독 전 재관찰 검증

가로 각도 보정 1.79, Original 18픽셀 판독기, 서로 다른 두 프레임 확인, 같은 면 30cm 판정은 기존과 같다. 11월 18일 14:52의 103번 로그만 이번 수정에 사용했다. 이전 실험에서 전체 성적을 확인한 나머지 5개 로그는 이번 수정의 조건을 정하는 데 사용하지 않았다. split.json은 영상 확인 전에 나눈 목록이며 frozen.sha256은 검증 영상 검토 전에 고정한 코드와 목록의 해시다.

## 관측과 변경

14:52의 첫 판독 전 영상에는 로봇팔 받침의 103번 인쇄물이 보였다. 199.070~200.168초의 12프레임 모두 기존 검출기가 테두리를 잡았다. 그 방향의 연속된 라이다 반사는 3.13~3.42m였고 기존 관찰 코드는 2.6m 이내의 면만 생성했다. 새 후보는 기존 면 연결이 실패할 때 카메라가 가리킨 좁은 방위에서 2.6~8m의 라이다 점을 직접 검사한다. 인접한 반사점 4개 이상이 이어지고 점프·깊이 단절이 없으며, 카메라 광선이 지지점 사이의 평면과 교차해야 한다. 거리나 마커 ID를 추측해 지점을 추가하지 않는다.

## 녹화 재생

시각은 미션 시작 후 초다. 첫 재관찰 요청이 최초 18픽셀 영상 판독과 최초 관측 로그 중 이른 시각보다 엄격히 앞서고, 관찰자 쪽 마커 면 30cm 안을 가리켰는지 비교했다. 평가용 5개 중 2개에 7번 또는 103번의 기준 좌표가 있다.

| 구분 | 주행 · ID | 첫 판독 | 기존 판독 전 요청 | 수정판과 영상 확인 |
|---|---|---:|---|---|
| 개발 | 11/18 14:52 · 103 | 200.267 | 없음 | 192.269초에 해당 면을 재관찰 대상으로 선택했다. 71.289초에 먼저 다른 표식을 선택해 ‘첫 요청 일치’는 실패했다. |
| 평가 | 11/17 22:19 · 103 | 21.686 | 없음 | 왼쪽에서 들어오는 표식에 대해 21.586초에 첫 테두리와 면 연결이 있었고 21.686초에 두 번째 확인과 첫 판독이 동시에 일어났다. 두 버전 모두 같은 프레임에서 회전을 요청했다. |
| 평가 | 11/18 12:58 · 7 | 208.723 | 없음 | 강한 역광 속 표식이 왼쪽에서 일부만 보였다. 첫 유효 테두리와 첫 판독이 같은 프레임이었다. 수정판은 면을 연결했으나 두 번째 확인과 회전은 208.821초였다. |

보류한 7번·103번 두 사례에서 판독 전 해당 면 선택은 두 버전 모두 0/2였다. 평가 5회의 전체 즉시 요청은 9회에서 11회가 됐다. 11/18 15:54 주행에 추가된 370.690초 장면은 표식으로 확인하기 어려운 배경이었다. 현재 후보는 실물 기본 정책에 적용하지 않았다.
