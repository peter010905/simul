# Flow v3 · MPPI의 넓은 표면 관찰

옆쪽 벽이나 장애물의 중심을 바라보는 기존 회전을 확장한다. 선택된 표면을 따라 라이다 반사점이 10개 이상 이어지고 폭이 22cm 이상이며, 중심을 지나 같은 방향으로 8° 이상 더 볼 수 있을 때 적용한다. 모서리나 끊어진 반사 너머로 연장하지 않는다. 확장량은 실제로 보이는 면의 끝, 24°, 카메라 수평 시야각의 3분의 1 중 가장 작은 값으로 제한하며 한 번의 회전 요청은 최대 130°다. 강한 근거가 없는 면은 중심만 향한다. 이 판단에는 마커가 실제로 붙어 있다는 정보가 없다.

**실물 로그 재생** · `20261118T082353-9f8e401d05`의 측면 관찰 10건을 기준으로 시각이 가까운 라이다와 위치를 골랐다. 기존 요청과 재생 중심각이 10° 이내로 일치한 6건 중 4건에서 9.4~12.9° 더 회전하는 요청이 나왔다. 2건은 기존 각도였다. 나머지 4건은 목표 선택이 다르거나 후보가 없어 비교에서 제외했다. 해당 주행 당시의 실제 궤적을 바꾼 결과는 아니다. 설치 환경에서 `python3 replay.py RUN_DIRECTORY`로 재생할 수 있다.

**Gazebo** · 기존 측벽 시험 장면 `side_wall.yaml`에서 왼쪽 81° 중심을 지나 105°까지 회전했고 Nav2가 회전을 완료했다. 50초 시험에서 ID 42 확인·접근, 범퍼 접촉 0회였다. 이 한 장면은 전체 과제 성공률을 측정하지 않는다.
