# Mixed v1.5.1-wall-sections

v1.5.1-balanced를 바탕으로 만든 별도 시뮬레이션 후보판이다. 상자 근처에서 새 목표를 고를 때, 마커 단서가 한 번도 없었더라도 아직 영상으로 확인하지 못한 벽 구간이 차례를 얻을 수 있다.

- 기존 Mixed가 만든 벽 관찰점만 사용한다. 실제 RGB 처리 시각과 LiDAR·TF가 일치하고 판독 거리·입사각 조건을 충족한 면은 기존 방향별 카메라 관찰 기록에서 제외 대상으로 식별된다. 이미 충분히 확인한 면은 새 관찰점을 만들지 않는다.
- 관찰점의 표면을 odom 기준으로 법선 방향·수직 위치·벽을 따른 약 1.2m 구간에 연결한다. 관찰점이 처음 선택 가능했던 시간과 마지막으로 그 구간에 목표를 보낸 시간을 기억한다. 목표를 보냈다는 사실은 카메라 관찰 완료로 계산하지 않는다.
- 10분 임무에서는 약 60초간 기다린 미관찰 구간이 있으면 다음 일반 목표 선택 때 한 곳을 검토한다. 짧은 임무에서는 임무 시간의 10%를 18~60초 범위로 사용한다. 오래 기다리고 격자 경로 길이가 짧은 구간을 먼저 선택하고 남은 시간 안에 이동·관찰할 수 있는지 추정한다. 이 판단에는 frontier 이득이나 마커 후보가 필요하지 않다.
- 예약한 벽 관찰 뒤에는 아직 볼 내부 면이 있으면 다시 내부 목표에 기회를 준다. 같은 벽 구간은 두 주기 동안 다시 예약하지 않는다. 일반 상자 재검토가 예약된 벽 이동을 즉시 취소하는 경로를 막고, 기존 마커 판독·접근과 Nav2·안전 중단 경로를 유지한다.
- 시간과 거리는 근사치다. SLAM이 같은 벽을 조각내거나 실내 구조물을 벽으로 분류할 수 있고, 고른 관찰점까지 실제로 갈 수 있는지는 Nav2 실행 결과로 확인해야 한다. 아직 지도에 나타나지 않은 벽은 기존 공간 탐색으로 발견해야 한다.

## 설치

원본 서명 목록과 설정을 검사하고 새 경로에만 소스와 설정을 복사한다. 아래 절차는 시뮬용 workspace를 빌드한다.

```bash
python3 policy_candidates/2026-11-21_v151_wall_sections/install.py \
  policy_releases/2026-11-21_mixed_camera_sync_v151 ~/flow_v151_wall_sections_ws
cd ~/flow_v151_wall_sections_ws
source /opt/ros/jazzy/setup.bash
colcon build --symlink-install --packages-select osp_mission
```
