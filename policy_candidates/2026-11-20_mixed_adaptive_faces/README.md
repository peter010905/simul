# Mixed · 공간 맞춤 면 관찰

8780 시뮬레이션 보드에서 별도로 선택하는 정책이다. 각 면을 향하는 방향과 옆 방향으로 관찰 위치를 샘플링한다. 상자와 벽 사이에서도 양쪽 장애물로부터 지도상 여유 32cm를 확보하고, 카메라에 면이 들어오며, 로봇 위치와 연결된 후보를 고른다. 첫 관찰을 시작하려면 한 면에서만 이 조건을 만족해도 된다. 벽 관찰 위치로 이동하는 중에 도달 가능한 미관찰 내부 표면이 확인되면 그 표면을 다시 우선한다. 기존 마커 접근과 복구 우선순위를 유지한다.

## 이전 실물 로그 재생

저장된 SLAM 지도와 당시 비용지도를 사용했다. 다른 면을 이미 본 것으로 두고 F1·F2를 각각 한 번씩 선택시켰다. 당시 임시 제외 목록과 카메라 관찰 이력은 재현하지 않았다. 선택한 위치까지 당시 로봇 자세에서 NavFn 경로를 계산했다.

| 기록 시점 | 면 | 면에서 앞쪽 / 옆쪽 이동 | 경로 길이 | 경로상 최소 지도 여유 |
|---|---|---|---:|---:|
| 75.15초 | F1 | 50 / +30cm | 2.07m | 51cm |
| 75.15초 | F2 | 45 / −30cm | 1.31m | 47cm |
| 86.81초 | F1 | 50 / +30cm | 3.02m | 40cm |
| 86.81초 | F2 | 50 / −30cm | 2.19m | 40cm |

네 경로 모두 목표 오차 5mm 이내였다. 여유는 로봇 중심에서 지도상 비자유 셀까지의 거리다. 실물 로컬 컨트롤러의 통과 여부는 별도 검증이 필요하다.

## 같은 월드에서의 Gazebo 비교

배치 시드 546568814. 이전 월드와 출발 자세를 8780에서 다시 사용했다. 완주 조건은 세 ID 각각 판독·등록 및 실제 로봇 중심 기준 1.5m 이내 접근이다.

| 측정값 | 이전 center | 공간 맞춤 |
|---|---:|---:|
| 종료 | 600초 시간 초과 | 210.964초 완주 |
| 등록 및 접근 ID | 7, 32 | 7, 32, 103 |
| 상자 마커 | 1/2 | 2/2 |
| 가운데 표면으로 보낸 목표 | 0 | 8 |
| 범퍼 이벤트 | 0 | 0 |

새 회차의 마커별 최단 거리는 7번 0.839m, 32번 0.812m, 103번 0.573m였다. 이번에는 벽 단계에 들어가기 전에 탐색을 마쳤다. 벽 목표로 이동하다 가운데 면을 다시 우선하는 동작은 별도 통합 검사에서 확인했다. 동일 배치 한 번을 비교한 결과다.

이전 회차 `center-track-1XdW3igN`. 새 회차 `adaptive-track-4KJqzbo1`. 보드에서 새 회차를 열어 전체 211초 영상을 재생할 수 있다.

## 재현 파일

- `adaptive_faces.py`는 면별 후보를 만들고, `center_wall.py`는 관찰 순서를 정한다.
- `phased_hybrid.py`는 관찰 목표를 기존 주행과 연결한다. `install.py`는 준비된 일반 표면 Mixed를 별도 작업공간으로 복사해 설치한다.
- `board.patch`는 기존 장애물 우선 v2를 제공하는 시뮬 보드에 이 선택지를 추가한다.
- `replay_faces.py`는 두 시점의 관찰점과 NavFn 검사 입력을 재생한다. `test_schedule.py`, `test_wall_interrupt.py`는 면별 선택과 벽 주행 중 우선순위 복귀를 검사한다.
