# Mixed v1.5.2.26 · Mission Trail

원본 Focus Continuity에서 시작해 [Partial Face](../2026-11-24_v152_partial_face/README.md)의 상자 면 처리를 포함하는 별도 후보다. 현재 구역의 작업을 마치고 새 구역을 고를 때 기존 주행 기록 전체를 참조한다.

상자 5개 배치 2445263333에서 .25는 600초 동안 88.55m를 이동해 상자 마커 두 개를 확인하고 남서쪽 벽 마커를 놓쳤다. 408.84초에 동쪽으로 9.0m 경로를 선택하며 그 목적지가 최근 궤적에서 약 6.5m 떨어졌다고 기록했다. 실제 궤적상 이 지점의 1.66m 옆을 108.6초에 통과한 적이 있었다. 일반 새 구역 선택은 200초, 반복 탈출 때의 원거리 후보 선택은 170초 동안의 주행만 기억했다.

.26은 기존 `ExplorationMemory`의 0.6m 오도메트리 셀마다 실제 지나간 좌표를 한 개 기록한다. 새 구역과 반복 탈출의 목적지를 평가할 때 이 좌표와 최근 세밀한 궤적을 함께 사용한다. 과거 통로를 경유할 수 있고, 유효한 마커 단서·미관찰 상자면·별도 벽 관찰 목표는 이전에 지나간 곳에도 접근할 수 있다. 다녀간 셀은 카메라 관찰 완료로 처리되지 않는다.

동일한 408.84초 SLAM 스냅숏에서 이전 계산을 재생하면 세계 좌표 (8.44, 3.82), 수정 후에는 (−3.44, −4.45)를 선택했다. 예상 격자 경로는 각각 9.0m와 8.8m였다. 이 재생은 당시 Nav2 비용지도와 실패 제외 목록을 복원하지 못했다. 실제 마커 발견과 장애물 회피는 별도의 640×480·5fps 시험장 주행으로 채점한다.

`install.py FOCUS_WORKSPACE NEW_WORKSPACE`로 별도 설치한다. 원본과 개발 중간 버전은 개별 실행할 수 있다.
