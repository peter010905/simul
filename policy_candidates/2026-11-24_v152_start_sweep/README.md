# Mixed v1.5.2.31 · Start Sweep

.30의 1.5m 한 프레임 판독을 유지하며, 주행을 시작할 때 주변을 한 바퀴 촬영하고 이미 마커를 찾은 상자는 다음 관찰 목표에서 제외한다. 시험 조건은 상자 하나에 마커가 최대 한 개다.

## 출발 시 관찰

센서·지도·Nav2 준비 점검과 필요한 도크 이탈 후, 첫 이동 목표에 앞서 Nav2에 제자리 2π 회전을 요청한다. 회전 중에도 마커 검출과 지도 갱신을 계속한다. 회전 액션의 진행량과 성공 상태를 실행 로그에 남긴다. 센서 끊김으로 회전이 취소된 경우 남은 각도만 한 번 재시도한다. 범퍼 접촉이나 충돌 검사로 회전을 마치지 못하면 기존 안전 처리에 맡긴다.

## 상자 처리

등록된 마커의 지도 좌표를 현재 SLAM 점유 격자의 표면과 대조한다. 표면 근처에 유일한 점유 물체가 있고 그 크기와 두께가 상자 범위에 들며 기존 탐색기가 내부 물체로 구분한 경우, 그 상자의 남은 일반 표면과 사각형 맞춤으로 생긴 면을 목표 후보에서 뺀다. 마커의 1.5m 접근 작업과 주변 벽의 관찰 작업은 계속한다.

목표를 다시 고를 때 현재 등록 목록과 지도로 연결 관계를 다시 계산한다. 서로 붙은 상자와 벽을 구분하기 어렵거나 일부만 매핑되어 형태를 판단하기 어려우면 더 관찰할 수 있다. 상자를 통행 금지 구역으로 만들지 않으므로 다른 목표를 향하는 경로가 그 옆을 지나갈 수 있다. 실행 기록의 `marked_box_ids`는 연결된 마커 ID이고, `suppressed_box_face_groups`는 해당 계획 시점에서 제외한 표면 후보 묶음 수다.

서쪽 벽 재시험에서 .30은 600초에 2/3, .31은 547.2초에 3/3이었다. 서쪽 벽 448번을 4.2초에 등록하고 27.7초에 근접 확인했다. 총 주행 거리는 86.6m에서 93.2m로 늘었다. 이 비교에서는 두 기능을 함께 바꿨다.

선별 회귀검사 33개 중 30개가 통과했다. 도크 이탈 검사 3개는 모의 객체에 취소 시각 필드가 없어 .30과 .31에서 동일하게 실패했다. 실제 로봇에서의 도크 이탈과 회전은 별도로 검증해야 한다.

## 실물 주행 대시보드

[실물 보드](http://192.168.252.2:8767/)의 정책 목록에서 `Mixed v1.5.2.31 · Start Sweep`을 선택하고 `1. 주행 준비`를 누른다. 준비가 끝나면 `2. 출발` 버튼이 활성화된다. 준비와 출발은 모두 VM의 `~/v15231_start_sweep_640_1124_ws`를 사용한다. 로봇의 유선 DDS 설정, 실물 시계, 공유 카메라와 기존 안전 점검을 사용한다.

배포할 때 두 단계 조작을 지원하는 실물 보드에 적용한 차이는 [physical_board.patch](physical_board.patch)에 보관했다. [버전 연결 테스트](test_physical_board.py)는 준비와 출발이 같은 작업공간을 선택하는지, 실제 주행 설정을 전달하는지 확인한다. 이 테스트는 로봇에 이동 명령을 보내지 않는다.

## 의자 92개 배치 재시험

이전 의자 시험장(4101)에서 회전 중 IMU 수신이 8초간 0건이었다. 바퀴 오도메트리는 같은 시간 102건을 수신했다. 출발 시 실제 기체는 약 2.6바퀴 돌았지만 Nav2의 회전 진행값은 0으로 남아 32초에 시간 초과했다. 이 회차는 129.8초에 중단하고 점수 집계에서 제외했다.

재시험에는 VM의 `~/yeonslay-chair-comparison-4101/chairs-runtime31`을 사용했다. 책상 14개, 의자 92개, 충돌 형상 1,010개, 마커와 출발 자세를 보존했다. 정상 시험장의 IMU·접촉 시스템과 4ms 물리 간격을 적용했다. 재시험에서 8초간 IMU 250건이 수신됐고 출발 회전은 360.5°에서 성공했다. 첫 시뮬 90초의 평균 속도는 실시간의 0.177배에서 0.469배로 바뀌었다.

600초에 북쪽 벽 32번을 등록하고 1.5m 이내 접근을 완료했다. 상자 7번은 판독 0회, 15번은 125회 판독했지만 거리값을 확보하지 못해 등록 0회였다. 기록된 이동 거리 68.5m, 범퍼 접촉 0회, 전체 실제 소요 시간 26분 9초였다. 시작 좌표와 자세를 일치시킨 원본 기록 및 수정 회차의 100초 이내 마지막 계획 시점 위치 오차는 각각 4.69m와 0.01m였다. [의자 시험 상세 결과](../../experiments/2026-11-24_focus_multimap/v15231_chairs4101.json)
