# Mixed v1.5.1-wall-balance

동결 v1.5.1-balanced에 벽 구간의 카메라 관찰 부족과 방향별 대기시간을 반영한 별도 시뮬레이션 후보다. 기본 주행, 마커 후보·판독, 상자 관찰점 생성과 Nav2의 설정을 그대로 재사용한다.

현재 SLAM의 실제 벽 표면 표본을 방향별로 모아 RGB 관찰 완료 비율을 구한다. 방향은 처음 벽을 관측한 SLAM 축을 odom에 고정한 네 법선 그룹이다. 실험의 동서남북에 대응하는 이름은 평가기가 종료 후 정답 좌표에서만 붙인다. 축은 임의의 실내 배치에도 사용할 수 있지만 불규칙한 대각선 벽은 같은 그룹에 묶일 수 있다.

상자와 벽의 일반 선택점에서 45초 이상 기다린 벽 구간 중 안전하고 시간 내 갈 수 있는 후보를 검토한다. 카메라 관찰 완료 비율이 낮은 방향, 대기시간이 긴 방향, 아직 확인하지 못한 구간에 점수를 준다. 135초 이상 밀린 방향이 있으면 오래 기다린 방향을 먼저 검토한다. 거리와 예상 관찰 시간을 계산해 남은 시간 안에 갈 수 있는 후보를 쓴다.

예약한 벽 목표 다음에는 새 내부 면이 있으면 그 면에 차례를 준다. 같은 구간의 재예약은 90초 동안 유예한다. 목표 전송·도착으로 관찰 완료 비율을 올리지 않는다. 기존 촬영 시각·TF·스캔이 일치하는 영상 증거가 있어야 비율이 증가한다. 안전 격자 여유, Nav2 costmap 연결성과 실패 목표 제외, 충돌 감시는 기존 경로로 적용된다.

실제 영상 시야에 들어온 구간이 부족하더라도 아직 벽으로 분류되지 않은 면에는 이 예약이 적용되지 않는다. 그런 공간은 기존 frontier 탐색과 일반 면 관찰에 의존한다. 네 방향 모두에 안전하고 도달 가능한 위치가 있다고 가정하지 않는다. 지도 분절과 잘못된 법선 분류는 성능에 영향을 줄 수 있다.

## 재현

원본 v1.5.1 소스와 설정의 해시를 검사하고 새로운 작업공간에 설치한다.

```bash
python3 policy_candidates/2026-11-21_v151_wall_balance/install.py \
  policy_releases/2026-11-21_mixed_camera_sync_v151 ~/flow_v151_wall_balance_r2_ws
cd ~/flow_v151_wall_balance_r2_ws
source /opt/ros/jazzy/setup.bash
colcon build --symlink-install --packages-select osp_mission
```

네 방향의 지속 대기, 상자 관찰로 복귀, 실제 영상과 전송 횟수의 구분, 안전 여유·마커 접근 관련 ROS 테스트 32개를 통과했다. 테스트는 실물 성능의 측정값이 아니다.
