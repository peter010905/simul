# Mixed v1.5.1-adaptive-survey

동결된 v1.5.1-balanced를 기반으로 만든 Jazzy 시뮬레이션 정책이다. 실험은 카메라 480×480·5 FPS와 같은 Nav2·SLAM·검출 사전을 사용한다. 정책 입력은 로봇이 받은 지도, costmap, 센서, 실제 카메라 노출 및 마커 관측 기록이다. 장면 파일의 상자 좌표, 마커 위치, 벽의 방향은 평가기에서만 읽는다.

## 목표 선택

1. 원래의 확인된 ID 접근과 판독 후보 재관찰을 먼저 처리한다. 일반 목표를 고를 때는 현재 SLAM과 Nav2 costmap에서 도달 가능성이 있는 벽면·장애물 면·미지 공간 경계를 함께 비교한다.
2. 카메라 초점거리·시야각, 표면 방향, 가림, 카메라가 아직 확인하지 못한 면의 길이를 계산한다. 같은 관찰점에서 벽과 상자가 함께 보이면 양쪽에 이득을 준다. 실제 촬영으로 얻은 면 기록만 관찰 완료로 인정한다.
3. 회전과 이동에 걸릴 시간, 최근 같은 주변을 본 횟수를 비용으로 센다. 같은 구역의 서로 다른 면도 구분한다. 갈 수 있는 목표가 계속 있었던 종류와 구역의 대기시간을 따로 기록한다. 남은 시간에 갈 수 있는 범위에서 오래 밀린 구역이 차례를 얻는다. 지도가 닿지 않은 곳은 frontier가 맡는다.
4. 다른 면이 막혀도 현재 볼 수 있는 상자 면은 관찰한다. 한 면에서 마커를 확인한 상자는 우선순위만 조금 낮춘다. 네 면이 실제 카메라 기록과 모두 맞으면 상자 관찰 작업을 닫는다. 추후 지도에서 형태가 바뀌어 빈 면이 확인되면 다시 연다. 직사각형으로 판정되지 않은 물체는 지도에서 보이는 표면을 사용한다.
5. 같은 면으로 두 차례 보냈는데 카메라로 보지 못한 경우, 45초가 지나고 원래 위치 주변에서 안전하고 연결된 관찰 표본이 두 곳 이상 새로 열렸을 때 추가 시도를 한 번 허용한다. 이전 두 관찰점과 충분히 떨어진 다른 위치만 허용한다. 이 판단과 별도로 Nav2가 경로와 충돌 여부를 검사한다.

## 작은 단서와 계산 비용

- 일부가 가려진 작은 사각형은 명암이 다른 연결 성분에서 추가 후보를 만든다. 처리량은 영상 16구역에서 각 두 성분으로 제한한다. 기존 흰 여백·검은 테두리·내부 무늬 검사와 상한 8후보를 적용한다. 한 마커 번호를 읽은 프레임에서도 그 사각형 밖에 있는 다른 무늬를 검사한다.
- 6~9px 단서가 카메라 노출 시각 기준으로 같은 방향에 두 번 남고 화면 가장자리로 빠지면 6° 이내의 짧은 재관찰을 요청할 수 있다. 미션 최대 두 번이며 위험 신호·진행 중인 마커 접근·남은 시간·재요청 간격을 확인한다. 이 요청으로 목적지를 만들거나 ID를 확정하지 않는다.
- 흑백 무늬로 이동할 때 격자 경로의 단위인 미터를 그대로 사용한다. 기존 구현은 여기에 지도 해상도를 다시 곱했다. 연결성은 실제로 검토하는 관찰점의 SLAM 셀 중심에서 Nav2 연결 성분과 대조한다.
- 기존 안전 격자의 상하좌우 최단 거리를 SciPy로 계산한다. 좁은 시작점 처리, 알려지지 않은 셀, 지도 경계, 도착점 여유는 원래 필터를 통과해야 한다. 실제 Nav2 플래너는 목표를 전송한 후 경로를 검증한다.

## 팀원용 설치

```sh
bash team-sim.sh setup ~/simul-ws/adaptive --policy adaptive-survey
bash team-sim.sh run ~/simul-ws/adaptive 112601 --check
bash team-sim.sh run ~/simul-ws/adaptive 112601
```

`center_wall.jsonl`에는 선택 종류, 종류·구역의 대기시간, 예상 이동·회전 시간, 벽·장애물 카메라 이득과 재시도 여부가 기록된다. 장면별 검증과 미완료 사유는 [실험 결과](../../experiments/2026-11-22_v151_adaptive_survey/README.md), 개인 환경 설정은 [Jazzy 실험실](../../docs/team-policy-lab/README.md)에서 확인한다.

카메라가 볼 수 없는 높이, 물체에 밀착된 면, 복잡한 동적 장애물, 실제 노트북·랜선 반사와 저조도는 별도 검증 대상이다. 가림 검사는 2D SLAM과 카메라의 관찰 이력을 사용하므로 카메라 높이에서만 시야를 막는 물체를 완전히 표현하지 못한다.
