# 같은 면에서 반복된 흑백 사각 테두리 우선 재관찰

Flow v3의 11월 18일 주행 4개를 동일한 경로와 시각으로 재생했다. 카메라·라이다·자세를 동기화한 영상 11,600장을 사용했다. 표식의 ID를 입력으로 받지 않는 정책 후보이며, 출력은 재생에서 선택한 목표와 동작이다.

|---|---:|---:|---:|---|
| 17:08 | 103 | 112.224 | 없음 | 111.824초에 같은 면 선택. 화면 중앙에서 0.12도 차이여서 0.5초 유지 |
| 17:23 | 7 | 201.373 | 201.391 | 발견 전 선택 없음 |

| 17:43 | 103 | 62.192 | 62.211 | 발견 전 선택 없음 |

기존 면 기억 방식은 네 주행 모두 마커 쪽을 발견 전에 목표로 고르지 않았다. 동일한 92개 목적지 선택 시점에 흑백 테두리의 우선순위를 높여도 기존과 똑같이 일반 면을 향한 23개 재관찰 목적지를 제안했다. 사각 단서로 바뀐 목적지는 0개였다. 17:08과 17:37 모두 같은 면에서 두 번째 테두리가 잡힌 뒤 해당 기준 시각까지 탐색 목적지를 다시 고르는 시점이 없었다.

카메라 프레임에서 즉시 고르는 조건은 전체 녹화에서 회전 4회, 시선 유지 2회를 제안했다. 첫 영상 판독 전에 맞는 면을 고른 건 17:08의 한 번이다. 당시 로그에 103번 좌표가 없어 영상 판독 중심과 같은 방향의 라이다 면을 사용했다. 첫 1초 안에 연결한 4개 위치의 중앙값을 썼고, 중앙값과 가장 먼 점의 거리는 12.4cm였다. 17:37은 관측 로그 기준으로만 0.020초 앞섰다. 나머지 두 주행에서는 첫 관측 전에 해당 위치에 연결된 반복 단서 자체가 없었다.

## 선택과 검증 방법

- 두 가지 밝기 이진화로 사각 외곽을 찾고, 밝은 여백·검은 테두리·내부의 양방향 밝기 변화를 검사한다. 두 영상에서 같은 위치에 보이는 물체도 로봇이 움직이면 다른 면일 수 있어, 촬영 시각의 카메라 자세와 라이다 면의 위치·방향을 맞춘다. 같은 방위에 25cm 넘게 깊이가 갈리는 후보는 버린다. 라이다가 보는 높이와 인쇄물 높이가 달라 위치 연결에는 오차가 있다.
- 서로 다른 두 프레임이 0.4초 안에 들어오고 위치 차이 10cm 이하, 법선 방향 차이 약 35도 이내, 크기 비율 0.60~1.67이면 반복 단서로 인정한다.
- 목적지 선택 방식은 같은 지도 경계·가시선·주행 거리 증가 상한·반복 제한을 통과한 사각 단서 면부터 시도한다. 즉시 재관찰 방식은 반복 단서가 들어온 프레임에서 면 하나를 선택한다. 카메라 중심에서 8도 이내면 0.5초 시선을 유지하고, 벗어나면 해당 각도로 돌려 0.5초 본다. 즉시 요청 간격은 12초이며, 같은 방향의 80cm 이웃에는 90초 간격을 둔다.
- 목표 선택과 별도로 기존 Original 18픽셀 판독기를 재생했다. 결과를 원래 ROS 마커 첫 관측과 각각 비교했다. 마커 위치에서 30cm 이내이고 관측자를 향한 면인지 확인하고, 기준 시각보다 **엄격히 앞선** 선택만 셌다. 실물의 실제 회전·정지와 발견 시간 단축은 측정하지 않았다.
