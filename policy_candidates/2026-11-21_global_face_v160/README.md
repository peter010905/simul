# Mixed v1.6.0 시뮬레이션 후보

벽·장애물·프런티어를 한 자리에서 비교하고, 영상에서 확인한 상자 면을 다음 계획에도 기억하는 실험판이다. 기존 v1.5.3에서 별도 작업공간을 만든다.

## 기준판에서 확인한 실행 경로

| 기능 | 실제 구현과 관찰한 제약 |
|---|---|
| 시작 | 실험 launch → `robot.launch.py` → SLAM, Nav2, 검출기, `Mission(planner='edge')`. 서비스 `/mission/start`가 준비 상태를 검사한 뒤 임무 시간을 센다. |
| 공간 탐색 | `edge_policy.options`가 안전격자 Dijkstra 거리와 접근 가능한 미지 공간 이득으로 이동 후보를 만든다. RGB 시야에 들지 않은 벽도 LiDAR 지도에는 일찍 나타난다. |
| 벽·장애물 | `PhasedHybrid.select → CenterWall.decide`가 SLAM 점유 성분, 자유공간, 표면 법선, Nav2 전역 costmap을 사용한다. 기존 단계 전환과 반복 방문 억제 조건에서 한 부류의 후보가 다른 부류를 밀어낼 수 있다. |
| 네 면 | 옛 `FullBox.choose` 50–54행은 한 면의 후보가 비면 상자 전체를 건너뛴다. 현재 부모의 `PhasedHybrid`는 여러 시점에서 확인한 `local_boxes`의 면을 개별 생성한다. 부모에는 지속적인 면별 실패 상태와 환경 변화에 따른 재시도를 결합한 작업표가 없다. |
| 카메라 | 검출기가 발행한 `/mission/processed_camera`의 실제 촬영 시각, TF, 250ms 이내 스캔 교차점으로 `EdgeCoverage.observe`가 격자 경계의 방향별 관찰을 누적한다. 지도 확장 시 근거를 다시 매핑한다. |
| 마커 | `Detector.on_rgb`의 기존 ArUco Original 판독, 여러 프레임의 ID·위치 합의와 근거리 RGB 확인을 사용한다. 약한 흑백 후보는 접근·재관찰에만 쓰인다. |
| 이동·실패 | `Mission.send / accepted / completed`가 Nav2 액션과 취소·재계획을 단독 관리한다. 주행 중 복구·센서 신선도·범퍼/낭떠러지 검사를 유지한다. |
| 종료 | 기준판은 목표 마커 접근 완료 또는 시간·안전 종료가 가능하고 빈 frontier에서 재탐색한다. 순수 지도 완성도만으로 마커 성공을 평가할 수 없다. |

## 새 목표의 선택과 완료

1. `face_tasks.py`가 여러 방향에서 직사각형으로 확인된 물체를 odom 좌표로 연결한다. 물체와 면의 위치·법선을 매칭하여 추정 순서가 바뀌어도 작업 ID를 유지한다. 비정형 물체는 기존 점유 성분의 외곽 표면을 이용한다.
2. `global_coverage.py`는 각 면의 중심 및 양옆, 벽 구간, 일반 장애물, 프런티어를 모은다. 안전거리, 알려진 자유공간과 costmap 연결성, 최근 실패 목표 제외 조건이 적용된다. 각 위치에서 가리지 않은 미관찰 벽과 물체의 길이, 미지 공간, 동시에 보이는 면 수를 계산한다. 벽과 물체의 이득을 각각 포화시켜 긴 벽 하나가 넓이만으로 계속 유리해지는 문제를 줄인다.
3. 가족별 대기시간과 미완료 면의 대기시간을 반영한다. 같은 상자는 최대 3회 또는 40초까지 인접 면을 우대하고 유효한 다른 작업이 있으면 양보한다. 90초 이상 대기한 유효 후보는 경로 검토 기회를 얻는다. 도달 가능한 모든 면의 완료를 보장하는 수학적 하한은 없다.
4. `path_review.py`가 상위 세 후보에 대해 실제 Nav2 `ComputePathToPose` 액션을 비동기로 요청한다. 반환 경로의 끝점과 길이, 변경된 현재 지도 및 실패 이력을 확인하고 최종 후보 하나만 기존 `NavigateToPose`에 전달한다. 확인된 마커 접근은 기존 경로로 우선 처리한다.
5. 한 촬영 위치에서 조건을 만족한 모든 방향의 벽과 장애물 경계를 함께 기록한다. 촬영 시각 TF, 영상 크기·초점거리, 표면 법선, 예상 픽셀 크기, 2D 가림 검사와 RGB 처리가 모두 필요하다. 카메라의 수직 시야는 설정한 마커 부착 높이에서 확인한다. 상자 면을 폭 방향 5구간으로 나눠 충분한 폭이 관찰돼야 `OBSERVED`가 된다. 착지나 LiDAR 스캔만으로 등록되지 않는다.
6. 안전한 위치가 없는 면은 `BLOCKED`, 계획·이동 실패 또는 도착 후 영상 증거 부족은 `FAILED`로 기록한다. 지도·costmap의 주변 상태 및 해당 측면의 연결성 변화 후 재검사하고, 실패 후에는 대기시간을 늘린다. 동일 지도에서 실패한 면은 3회 이후 지도 변화까지 보류한다. 통로가 영구히 열리지 않으면 미완료 사유를 남긴다.
7. `global_coverage.jsonl`에 실제 검증한 경로 길이, 후보군, 미관찰 표면, 물체별 4개 상태·근거·실패 이유, 등록 ID와 익명 단서를 기록한다. 독립 실험 평가기는 고정 시간 또는 동일한 마커 근거리 증명에서 멈춘다. 정책 단독 실행은 기본적으로 마커 접근 후에도 관찰 작업을 계속하며, 시간 제한 또는 가용 작업·추적 단서 소진 시 종료할 수 있다.

## 설정과 안전 여유

거리·판독 설정은 `coverage_marker_width_m`(기본 0.08m), `coverage_min_edge_px`(18px), `coverage_frames`(3회), `coverage_face_fraction`(0.70), `coverage_height_m`(0.45m)로 분리했다. 실제 카메라 intrinsics와 TF에서 이미지 크기와 시야를 구한다. 최소 픽셀과 부착 높이는 실물 보정값에 맞춰야 한다. 이는 표면을 볼 기회가 충분했는지를 추정하는 기준이다. 마커 부재를 증명하지 않는다.

Nav2 YAML, footprint, inflation, 충돌 감시, 속도, 회피·안전 중단과 ArUco 판독기는 부모 작업공간의 버전을 쓴다. 기존 0.32m 격자 여유를 유지한다. 한 면을 못 보더라도 나머지 세 면은 독립적으로 진행할 수 있다.
