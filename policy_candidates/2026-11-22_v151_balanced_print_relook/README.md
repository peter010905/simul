# Mixed v1.5.1-balanced · 스친 마커 재관찰

무작위 배치의 북쪽 벽에서 원본 카메라 한 장에 Original 149번이 최단 변 11픽셀로 읽혔다. 당시 R5는 다른 장애물 면을 보러 가고 있었다. 600초 동안 그 벽 마커의 최단 변이 18픽셀 이상이면서 네 모서리와 중심이 함께 보이는 기회는 0회였다. 같은 배치에서 Balanced는 40프레임의 기회를 확보하고 258.4초에 등록 후 접근을 마쳤다.

이 후보는 Balanced의 목표 선택과 Nav2 설정을 사용한다. 한 장에서 원본 해상도의 OpenCV 판독과 인쇄 무늬 대조를 모두 통과한 작은 표지가 화면 좌우 끝 약 11%에 들어오면 방향을 기억한다. 평소 ID 등록 기준은 18픽셀이고, 추가 관찰 대상은 최단 변 10픽셀부터 등록 기준 미만이다. 여러 판독 결과가 경합하거나 인쇄 테두리가 잘린 영상은 이 동작을 시작할 수 없다.

일반 탐색 목표로 이동 중일 때만 노출 시각과 현재 카메라 자세를 대조한다. 최신 위험 신호, 기존 마커 접근, 바닥 여유 32cm와 Nav2 회전 가능 여부를 확인하고 가던 목표를 저장한다. Nav2 회전 후 실제 처리 프레임을 기다린다. 기존 검출기가 추가 위치 단서를 얻으면 원래의 접근 절차로 넘기고, 추가 단서가 없으면 저장한 면의 관찰 방향과 이동 목표로 복귀한다. 같은 ID 또는 가까운 위치·방향에 대한 재요청을 제한한다. 회당 최대 8초, 600초 미션당 최대 두 번이다. 고장·안전 중단 시 복구는 기존 Nav2 및 미션의 처리를 따른다.

```bash
bash team-sim.sh setup "$HOME/simul-ws/balanced-print" --policy balanced-print-relook
```

Jazzy에서 새 검사 8개가 통과했다. 기존 판독·접근·복귀 검사 57개 중 원본과 새 후보 모두 54개가 통과했고, 양쪽에서 같은 기존 거리·시간 조건 검사 3개가 실패했다. 첫 배치의 11픽셀 원본 JPEG를 재생했을 때 ID 149에 대한 추가 관찰 후보가 나왔다. 이 재생으로 실제 두 번째 판독이나 접근 성공을 측정할 수는 없다. [독립 시험 배치와 채점 기준](../../experiments/2026-11-22_random_exam/balanced_print/enrollment.json)

이전 시험장 5회 원본 영상 12,238프레임을 같은 경로로 재생했다. 기존 정책이 등록하기 전에 화면 가장자리 조건을 만족한 4프레임은 모두 같은 번호의 실제 인쇄물 위치와 일치했다. 중복과 미션당 상한을 적용한 재관찰 기회는 세 번이었고, 각 주행의 원래 등록보다 17.8초, 20.3초, 57.8초 앞섰다. 이 시각은 단서가 나타난 시각이다.

개발용 R5 경로 3,000프레임에서는 149번보다 앞서 다른 정답 번호 두 개가 조건을 충족했다. 두 번 다 실제 회전으로 이어졌다고 가정하면 149번에는 남은 차례가 없다. 새 정책의 탐색 경로와 안전 판정이 달라지는 효과는 별도 무작위 주행으로 평가한다. [프레임별 재생 집계](../../experiments/2026-11-22_random_exam/balanced_print/development_replay.json)
