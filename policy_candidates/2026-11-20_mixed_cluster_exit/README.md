# Mixed · 상자 재방문 줄이기

벽 후보 기억판에서 출발한 별도 실험 정책이다. 카메라로 두 방향 이상 관찰했거나 등록 마커의 근거리 접근을 끝낸 상자만 대상으로 한다. 같은 상자에 지난 150초 동안 내부 표면 목표를 세 번 이상 보냈고 첫 목표와 마지막 목표 간격이 20초 이상이면, 그 주변의 일반 표면 조각을 잠시 뒤로 미룬다. 목표 횟수와 카메라 관찰을 따로 기록한다.

다른 상자에 속하거나 아직 관찰하지 않은 것으로 피팅된 면은 계속 선택할 수 있다. 등록 마커 추적과 강한 인쇄 단서가 먼저이고, 상자에 우선할 새 면이 없을 때는 저장된 작은 벽 단서를 확인한다. 다른 안전한 내부 표면도 없으면 반복 구역 중심에서 2.4m 이상 떨어진 정보량 높은 기존 탐색 후보를 고른다. 안전한 대안이 없으면 기존 선택으로 돌아간다. 근거리 면을 보지 못했다는 이유만으로 그 상자를 영구 완료 처리하지 않는다.

이탈 후보도 원래의 SLAM 경로, Nav2 비용지도 연결성, 제외 목표, 남은 시간 조건을 거친다. 이탈 이동 도중에는 새로 관측한 상자 면을 다시 확인할 수 있다. 위 규칙은 로봇의 카메라와 지도만 사용한다.

## 설치

ROS 2 Jazzy VM에서 벽 후보 기억판 소스가 준비된 상태로 실행한다.

```sh
source /opt/ros/jazzy/setup.bash
python3 policy_candidates/2026-11-20_mixed_cluster_exit/install.py ~/flow_v3_r32_wall_cues_final_ws ~/flow_v3_r32_cluster_exit_ws
cd ~/flow_v3_r32_cluster_exit_ws
colcon build --packages-select osp_mission
```

실물 보드에서는 **Mixed · 상자 재방문 줄이기**로 선택한다. 시뮬에서 동일 장면을 비교하려면 이 폴더의 `run_one.sh`에 준비된 원본 장면 이름을 준다. 예를 들어 `bash run_one.sh shared-track-fuAePeEx`는 별도 결과 디렉터리에 기록하며 기존 주행을 덮어쓰지 않는다.
