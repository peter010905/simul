v1.5.2.11을 기반으로 한 Gazebo 실험 후보. 상자에 처음 관찰 목표를 보낸 뒤 같은 상자에 속한 현재 미관찰 면을 모은다. 각 면의 안전한 관찰점은 기존 지도, 비용지도, 가림, 카메라 관찰 이력 검사에서 가져온다. 가능한 다음 면의 조합을 비교해 관찰할 수 있는 면 수를 최대화하고, 이동 거리가 짧은 순서를 우선한다. 방문 순서는 다음 결정에서 여전히 유효한 후보로 다시 확인한다.

면 사이의 이동비는 현재 지도에서 32cm 여유를 확보한 격자의 4방향 이동 거리로 추정한다. Nav2가 실제 주행을 담당한다. 회차의 남은 시간, 같은 상자에서 보낸 시간, 면 사이의 이동거리 한도를 적용한다. 시도한 면과 카메라로 본 면은 별도로 다루며, 당장 관찰점이 없는 면은 이후 탐색에 남긴다. 확인된 마커 접근과 반복 확인된 벽 단서는 기존 우선순위를 유지한다.
