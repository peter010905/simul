# Mixed v1.5.2.15 · 구역 우선 관찰

Focus Continuity에서 일반 탐색 목표를 고르는 부분을 따로 개선했다. 검증 중인 마커 ID는 같은 ID가 다시 보일 때 접근을 이어간다. 상자 면 판정, RGB 관찰 완료 판정, Nav2 충돌 검사, 범퍼 복구 및 1.5m 검증은 부모 구현을 사용한다.

- 벽과 장애물의 안전한 관찰 위치에 같은 경로 비용을 적용한다. 실제 FOV, 카메라 보정, 가림, 예상 픽셀 크기를 통과한 미관찰 표면을 함께 볼 수 있으면 보상한다. 실시간 SLAM 지도의 이동 거리를 사용하고 실제 주행 경로는 계속 Nav2가 계산한다.
- 2.2m 이내의 같은 구역에서 관찰할 면이 남고 이동 비용이 작으면 이어서 본다. 한 번의 방문은 4개 목표 또는 55초로 제한한다. 이전 구역이나 이미 시도한 면의 비용을 높이고, 미탐색 공간으로 갈 유효한 Frontier도 평가한다. 비어 있는 구역을 향해 다시 되돌아오는 횟수를 줄이려는 설계다.
- 일반 구역 탐색 중 익명 인쇄물 후보로 계획을 바꾸는 이동은 경로 길이 2.4m 이내로 제한한다. 6~10px의 작은 단서가 벽에 대응하는지 확인할 때는 각 카메라의 초점거리와 마커 크기 상한을 이용한다. 작은 후보가 멀리 있는 벽 목표를 만들려면 원본 구조나 실제 디코더가 확인된 표본이 반복돼야 한다. 두 위치에서 보인 약한 단서는 가까운 벽만 다시 본다.
- 시뮬 카메라는 640×480, 5fps다. 물리 로봇의 카메라 전송률과 주행 성능은 실물 검증이 필요하다.

```sh
python3 policy_candidates/2026-11-24_v152_regional_survey/install.py \
  ~/v152_focus_continuity_box1122_ws ~/v15215_regional_survey_1124_ws
```

시험장 라이브 SLAM 실행은 `run_exam_640.py`에 기존 `run_archived.py`와 시험장 인자를 전달한다. 기존 시험장에서 실행할 때 바뀐 두 카메라 값은 실행 기록의 `protocol.json`에 저장한다.

정사각형 입력만 허용하는 기존 관측기에는 [가로·세로 검증 패치](observer_dimensions.patch)를 적용한다. 기준값은 각각 `CAMERA_BENCH_WIDTH`와 `CAMERA_BENCH_HEIGHT`이다.
