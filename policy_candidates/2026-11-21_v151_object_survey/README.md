# Mixed v1.5.1-object-survey

원본 v1.5.1-balanced를 기반으로 상자별 네 면 관찰 완료와 미방문 공간 이동을 연결한 별도 시뮬레이션 후보다. 기존 wall-balance와 기존 주행 버전은 별도 작업공간에 보존한다.

확인된 직사각형 장애물을 odom 위치·면의 법선으로 추적해 객체 ID와 네 면의 작업 ID를 유지한다. 각 면은 PENDING, OBSERVED, BLOCKED, FAILED 중 하나다. 기존 촬영 시각·TF·LiDAR 교차점으로 누적한 카메라 관찰 표본이 면 너비의 70% 이상을 덮어야 OBSERVED로 처리한다. 원래 격자의 촬영 증거 기준을 사용하며 목표 전송·도착으로 상태를 올리지 않는다.

관찰 가능한 면이 있는 가까운 상자를 선택하면 남은 면을 이어서 수행한다. Nav2가 실패하거나 도착 후 관찰 회전을 마쳐도 증거가 부족하면 해당 면만 보류한다. 안전한 관찰 위치가 없는 면도 보류한다. 주변 SLAM·costmap 또는 연결성 변화가 있으면 다시 검토한다. 한 물체에서 90초를 넘으면 남은 면을 보류하고 다른 곳으로 갈 수 있다. 벽 뒤와 좁은 통로의 면을 강제로 관찰하려고 머무르지 않는다.

네 면이 모두 OBSERVED인 상자는 일반 표면 관찰 후보에서도 제외한다. 상자 근처에서 마커 하나를 찾았다는 이유로 네 면 완료를 선언하지 않는다. 물체 위치·면 추정이 충분히 바뀌면 상태의 유효성을 재검토한다. 완료 상태의 증거는 잠시 국소 직사각형이 사라졌다는 이유로 삭제하지 않는다.

당장 수행할 상자 면이 없으면 이전 로봇 위치와 충분히 떨어진 기존 이동 후보를 검토한다. 해당 후보는 기존 SLAM 여유 격자와 Nav2 costmap 연결성, 실패 지점 제외를 통과해야 한다. 탐색 정보량이 0.15 미만이어도 새로운 구역으로 이동하는 가치가 있다. 남은 시간에 이동과 관찰이 가능한 후보를 사용한다. 이 방문 기록은 실제 로봇이 계획을 세운 위치를 누적한 근사이므로 카메라 표면 커버리지와는 다른 지표다.

새로운 마커 ID의 검증·접근은 기존 미션이 담당한다. 익명 표면 단서가 상자 작업과 구역 이동을 반복 취소하는 경로를 제한하고, 마커 확인으로 취소됐던 구역 목표를 다음 선택에서도 우대한다. 계획한 구역에 실제로 도착했을 때 방문으로 계산한다.

## 한계

객체 식별은 기존 여러 시점의 관측과 국소 직사각형 맞춤에 의존한다. 네 면 모델이 확보되지 않은 비정형 물체는 기존 일반 표면 탐색을 사용한다. 상자 위치의 큰 오차는 객체 분리·재생성으로 이어질 수 있다. 완료한 상자에 대한 새 익명 픽셀 단서는 기존 검출기 경로를 사용하며 그 신뢰도는 실제 영상에서 별도로 검증해야 한다.

회전·영상에 의한 관찰 증거와 안전 여유, 원본 Nav2 설정을 함께 사용한다. 모든 면의 관찰 가능성이나 모든 지도에서의 완주를 보장하지 않는다.

## 재현과 검사

원본 소스 및 설정의 해시를 검증한 뒤 새 작업공간에 설치한다.

```bash
python3 policy_candidates/2026-11-21_v151_object_survey/install.py \
  policy_releases/2026-11-21_mixed_camera_sync_v151 ~/flow_v151_object_survey_r4_ws
cd ~/flow_v151_object_survey_r4_ws
source /opt/ros/jazzy/setup.bash
colcon build --symlink-install --packages-select osp_mission
```

새 회귀검사와 기존 안전·마커·흐름 검사는 50개 통과했다. 기존 이동 중 벽 관찰 플래그에 관한 테스트 1개는 부모 v1.5.1에서도 동일하게 실패한다. 그 결과를 감춰서 전체 통과로 표기하지 않는다.
